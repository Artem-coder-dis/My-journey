## ?. и ??

**?. (optional chaining) - Проверяет, существует ли то, что слева**

если `||` читается как «ИЛИ», а `&&` как «И», то `?.` читается просто «вопрос с точкой» или «если существует»

?. - это как "если", несколько вложенных if, только коротко

**Пример:**
`user?.friends?.[0]`

Если существует user, то идём дальше и проверяем, существует ли friends, если да, то берём элемент 0, если на какой-то проверке нет - undefined

Я сначала путался, что первым: ? или ., но можно привести простую аналогию: **если** (?) **то** (.). еслиСвойствоСуществует?.тоИдёмДальше

**Задача 1.** Возвращает name пользователя. Если user равен null или undefined - вернуть undefined

```js
function getName(user) {
    return user?.name
}

console.log(getName({name: "Анна"})) // "Анна"
console.log(getName(null))           // undefined
```

**Задача 2.** Возвращает первый элемент массива

```js
function getFirstItem(arr) {
    return arr?.[0]
}

console.log(getFirstItem([10, 20])) // 10
console.log(getFirstItem(null))     // undefined
```

А если объект будет пустым? Доступ к несуществующему свойству всё равно даст undefined

**Задача 3.** Если arr нет или длина меньше 4 - undefined

```js
function getFourthElement(arr) {
    return arr?.[3]
}

console.log(getFourthElement([1,2,3,4])) // 4
console.log(getFourthElement([1,2]))     // undefined
```

То есть если длина массива будет меньше 3-ёх индексов, то вернёт undefined, эта строка и есть проверка длины

---

**?? (nullish coalescing) - Если слева null или undefined - возвращает правое значение. Иначе - левое**

Читается «два вопроса» или «или если null/undefined»

**Пример:**
```js
null ?? "по умолчанию"    // "по умолчанию"
undefined ?? "запасное"   // "запасное"
0 ?? 77                  // 0 (0 - не null и не undefined)
"" ?? "строка"            // "" (пустая строка - не null)
false ?? true             // false
```

**Чем же отличается ?? от ||**

`||` заменяет **все** falsy-значения. `??` - только null и undefined

```js
0 || 65    // 65 (0 - falsy)
0 ?? 65    // 0 (0 - нормальное значение)

"" || "x"  // "x" (пустая строка - falsy)
"" ?? "x"  // "" (пустая строка - нормальное значение)
```

**Задача на комбинацию**

Возвращает product.price. Если нет - вернуть 100

```js
function getPriceOrDefault(product) {
    return product?.price ?? 100
}

console.log(getPriceOrDefault({price: 200})) // 200
console.log(getPriceOrDefault({})) // 100
```
Если не будет product, вернёт undefined, если не будет price, то тут есть подстраховка в виде ??, тогда вернёт 100


Ещё 5 интересных задач на комбинацию

**Задача 1**

```javascript
// Что выведет?
let a = null;
let b = undefined;
console.log((a ?? b) ?? (b ?? a));
```

<details>
<summary>Ответ</summary>

`null`

`a ?? b` → `undefined`, `b ?? a` → `null`, `undefined ?? null` → `null`. `??` всегда берёт левое, если оно не `null`/`undefined`, иначе правое

</details>

**Задача 2**

```javascript
// Что выведет?
let x = 0;
let y = "";
let z = false;
console.log(x ?? y ?? z ?? "конец");
```

<details>
<summary>Ответ</summary>

`0`

`x` равен `0` - это не `null` и не `undefined`. `??` сразу возвращает `0`, до остальных операндов дело не доходит

</details>

**Задача 3**

```javascript
// Что выведет?
let obj = { data: [] };
console.log(obj?.data?.[0] ?? "пусто");
console.log(obj?.data?.length ?? "нет длины");
```

<details>
<summary>Ответ</summary>

`"пусто"` и `0`

Первый: `obj?.data` → `[]`, `[][0]` → `undefined`, `??` → `"пусто"`

Второй: `obj?.data?.length` → `0`. `0` не `null`/`undefined`, `??` возвращает `0`

</details>

**Задача 4**

```javascript
// Что выведет?
let config = { server: { port: 0 } };
console.log(config?.server?.port ?? 3000);
console.log(config?.server?.host ?? "localhost");
```

<details>
<summary>Ответ</summary>

`0` и `"localhost"`

Первый: `port` равен `0`, `??` не срабатывает

Второй: `host` не существует → `undefined`, `??` → `"localhost"`.

</details>

**Задача 5**

```javascript
// Что выведет?
let users = [
    { name: "Анна" },
    null,
    { name: "Борис" }
];
console.log(users?.[1]?.name ?? "Нет имени");
console.log(users?.[3]?.name ?? "Нет имени");
```

<details>
<summary>Ответ</summary>

`"Нет имени"` и `"Нет имени"`

Первый: `users[1]` → `null`, `null?.name` → `undefined`, `??` → `"Нет имени"`

Второй: `users[3]` не существует → `undefined`, `undefined?.name` → `undefined`, `??` → `"Нет имени"`

</details>

**Итог:** 2 оператора лёгкие в освоении, но очень полезные и пригодятся на 1-ой работе
