## Логические операторы

Логические операторы работают с булевыми значениями и возвращают `true` или `false`

**`&&` - И (AND)**
Возвращает `true`, если **оба** операнда истинны

```javascript
console.log(true && true)   // true
console.log(true && false)  // false
console.log(false && true)  // false
console.log(false && false) // false
```

Пример 1:
```javascript
let age = 25
let hasLicense = true
console.log(age >= 18 && hasLicense) // true - оба условия выполнены
```

**`||` - ИЛИ (OR)**
Возвращает `true`, если **хотя бы один** операнд истинен

```javascript
console.log(true || true)   // true
console.log(true || false)  // true
console.log(false || true)  // true
console.log(false || false) // false
```

Пример 2:
```javascript
let isWeekend = true
let isHoliday = false
console.log(isWeekend || isHoliday) // true - хотя бы один выходной
```

**`!` - НЕ (NOT)**
Переворачивает значение: `true` становится `false`, `false` становится `true`

```javascript
console.log(!true)  // false
console.log(!false) // true
```

Пример 3:
```javascript
let isLogged = false
if (!isLogged) {
    console.log("Пользователь не вошёл")
}
```
