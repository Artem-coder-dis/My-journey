## Арифметические операторы

Арифметические операторы работают с числами и возвращают результат вычисления

**`+` - сложение**
```javascript
let sum = 5 + 3 // 8
```

**`-` - вычитание**
```javascript
let diff = 10 - 4 // 6
```

**`*` - умножение**
```javascript
let mult = 7 * 2 // 14
```

**`/` - деление**
```javascript
let div = 15 / 3 // 5
```

**`%` - остаток от деления**
```javascript
let mod = 10 % 3 // 1 (10 / 3 = 3 целых и 1 в остатке)
```

**`**` - возведение в степень**
```javascript
let pow = 2 ** 4 // 16 (2 * 2 * 2 * 2)
```

---

**Особенности оператора `+`**

`+` работает не только с числами. Если один из операндов строка - происходит конкатенация (склеивание):

```javascript
let result1 = 5 + "3" // "53" - число превратилось в строку и приклеилось
let result2 = "Hello" + " " + "World" // "Hello World"
```

Остальные операторы (`-`, `*`, `/`, `%`) работают только с числами и автоматически превращают строку в число:

```javascript
let result3 = "10" - 5 // 5 - строка "10" стала числом 10
let result4 = "6" * "2" // 12 - обе строки стали числами
```

---

**Приоритет операторов**

Как в математике: сначала `**`, потом `*`, `/`, `%`, потом `+`, `-`. Скобки `()` повышают приоритет:

```javascript
let result = 2 + 3 * 4 // 14 (умножение раньше сложения)
let result2 = (2 + 3) * 4 // 20 (скобки изменили порядок)
```
