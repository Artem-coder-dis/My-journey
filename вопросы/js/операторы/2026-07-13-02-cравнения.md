## Операторы сравнения

Операторы сравнения сравнивают два значения и возвращают `true` или `false`

**Строгое равенство `===`**
Проверяет равенство без приведения типов. Значения должны быть одинаковыми и по типу, и по значению

```javascript
console.log(5 === 5)     // true
console.log(5 === "5")   // false - разные типы
console.log(true === 1)  // false - разные типы
```

**Нестрогое равенство `==`**
Проверяет равенство с приведением типов. JS пытается превратить значения к одному типу перед сравнением

```javascript
console.log(5 == "5")    // true - строка превратилась в число
console.log(0 == false)  // true - false превратилось в 0
console.log(null == undefined) // true - особое правило
```

`null` и `undefined` равны только друг другу при нестрогом сравнении `==`

Они как два вида «пустоты». `null` - явная пустота (программист специально указал «ничего»). `undefined` - неявная пустота (значение не присвоили). JS считает их «равной пустотой» при `==`, но не при `===`

**Строгое неравенство `!==`**
Обратное к `===`. Возвращает `true`, если значения НЕ равны по типу или по значению

```javascript
console.log(5 !== "5")   // true - разные типы
console.log(5 !== 5)     // false - одинаковые
```

**Нестрогое неравенство `!=`**
Обратное к `==`. Сравнивает с приведением типов

```javascript
console.log(5 != "5")    // false - после приведения равны
console.log(5 != 10)     // true
```

**Больше / меньше `>`, `<`**

```javascript
console.log(10 > 5)   // true
console.log(3 < 1)    // false
```

**Больше или равно `>=`, меньше или равно `<=`**

```javascript
console.log(5 >= 5)   // true
console.log(4 <= 3)   // false
```

Я сначала часто путался: что идёт вначале `=` или `>`/`<`, но просто обратил внимание на название, говориться: **больше/меньше** (значит знак `>`/`<`) **или равно** (значит `=`)

---

**Правило:** всегда используй `===` и `!==`, если нет особой причины использовать `==`. Строгое сравнение предсказуемо и не приводит к неожиданным результатам

```javascript
// Неочевидные результаты ==
console.log("" == false)   // true
console.log([] == false)   // true
console.log(0 == "0")     // true
```

С `===` таких сюрпризов нет:

```javascript
console.log("" === false)  // false
console.log([] === false)  // false
console.log(0 === "0")    // false
```
