## JSON
JSON - это просто способ записать данные в виде текста, чтобы их можно было передать или сохранить. Расшифровывается как JavaScript Object Notation (JavaScript - обозначение объектов)

Есть 2 метода

JSON.stringify - превращает объект в JSON-строку:

**Задача 1.** нужно написать функцию, которая принимает объект и возвращает его JSON-строку

```javascript
function toJSON(obj) {
    return JSON.stringify(obj);
}

console.log(toJSON({title: "Книга", pages: 300, read: true})); // {"title":"Книга","pages":300,"read":true}
```

**Задача 2.** Дан объект user с полями name, age и массивом friends. Напиши функцию, которая превращает объект в JSON-строку и возвращает её. В исходном объекте есть метод greet(), который не должен попасть в JSON

```javascript
function saveUser(user) {
    return JSON.stringify(user);
}

const user = {
    name: "Анна",
    age: 25,
    friends: ["Борис"],
    greet() {
        return "Привет";
    }
};

console.log(saveUser(user)); // {"name":"Анна","age":25,"friends":["Борис"]}
```

Но как же метод greet() не попадает в JSON?

Всё очень просто, JSON не умеет хранить функции, поэтому stringify их пропускает автоматически
На работе ты часто будешь отправлять данные на сервер через fetch (в разделе асинхронность) с JSON.stringify который пропускает методы автоматически

JSON.parse - превращает JSON-строку обратно в объект:

```javascript
function fromJSON(str) {
    return JSON.parse(str);
}

console.log(fromJSON('{"brand":"Toyota","year":2020}')); // {brand: 'Toyota', year: 2020}
```

**Задача 3.** Напиши функцию, которая принимает JSON-строку массива и возвращает массив

```javascript
function parseArray(str) {
    return JSON.parse(str);
}

console.log(parseArray('[1,2,3]')); // [1,2,3]
```

**Задача 4.** Дана JSON-строка объекта с массивом. Распарси (то есть преврати строку в объект через JSON.parse) её в объект и выведи первого друга

```javascript
const obj = '{"name":"Анна","friends":["Борис","Вика"]}';
const parsed = JSON.parse(obj);

console.log(parsed.friends[0]); // Борис
```

**Задача 5.** С сервера пришла JSON-строка с информацией о студенте: '{"name":"Иван","grades":[5,4,5],"address":{"city":"Москва"}}'. Напиши функцию, которая парсит строку и возвращает объект. Затем выведи средний балл студента

```javascript
function parseStudent(strInJSON) {
    const obj = JSON.parse(strInJSON);
    let sum = 0;

    for (let i = 0; obj.grades.length > i; i++) {
        sum += obj.grades[i];
    }

    return `Средний балл ${(sum / obj.grades.length).toFixed(2)}`;
}

const strInJSON = '{"name":"Иван","grades":[5,4,5],"address":{"city":"Москва"}}';
console.log(parseStudent(strInJSON)); // Средний балл 4.67
```

Что вообще происходит?

Сначала мы сохраняем результат в переменную obj и дальше работаем с ней

Создаём переменную sum куда будет складываться результат с цикла for по массиву grades который имеет значение [5,4,5] (с помощью i проходим по значениям массива)

Далее после цикла мы возвращаем строку "Средний балл " с выражением (sum / obj.grades.length).toFixed(2) который делит сумму (14) на длину массива (3) и с помощью метода toFixed(2) округляем значение до 2 цифр после запятой, без округления ответ был бы 4.666666666666667

**Глубокая копия.** Она объединяет 2 метода

Тут я немного заметил схожесть с методом массива map:

map - берёт массив, создаёт новый массив, исходный не трогает, но копирует только верхний уровень (поверхностная копия)

JSON.stringify + JSON.parse - берёт объект, создаёт новый объект, исходный не трогает, копирует все уровни (глубокая копия)

**Что такое поверхностная и глубокая копия:**

Поверхностная копия - копируется только первый уровень. Вложенные объекты или массивы не копируются, а передаются по ссылке

```javascript
const original = [1, 2, {a: 3}];
const copy = original.map(item => item);

copy[2].a = 99;
console.log(original[2].a); // 99 - исходный изменился, потому что вложенный объект - ссылка
```

Глубокая копия - копируются все уровни. Вложенные объекты и массивы тоже становятся новыми, независимыми

```javascript
const original = [1, 2, {a: 3}];
const copy = JSON.parse(JSON.stringify(original));

copy[2].a = 99;
console.log(original[2].a); // 3 - исходный не изменился
```

**Задача 6.** Дан объект user. Создай его глубокую копию, измени в копии city на "Питер", выведи оба объекта. Исходный не должен измениться

```javascript
const user = {name: "Борис", city: "Москва"};
const copy = JSON.parse(JSON.stringify(user));

copy.city = "Питер";

console.log(user); // {name: 'Борис', city: 'Москва'}
console.log(copy); // {name: 'Борис', city: 'Питер'}
```

**Задача 7.** Напиши функцию которая принимает два объекта, создаёт новый объект, объединяющий оба, и возвращает его JSON-строку. Исходные объекты не должны измениться

```javascript
function mergeAndStringify(obj1, obj2) {
    const result = {};

    for (let key in obj1) {
        result[key] = obj1[key];
    }

    for (let key in obj2) {
        result[key] = obj2[key];
    }

    return JSON.stringify(result);
}

console.log(mergeAndStringify({a: 1, b: 2}, {b: 20, c: 30})); // '{"a":1,"b":20,"c":30}'
```

Сначала мы создаём переменную result и первым циклом копируем в неё obj1

Вторым циклом мы проходимся по obj2 и если в result есть повторение, то мы просто перезаписываем результат

В конце возвращаем JSON-строку, не объект

Методы и undefined исчезают, а NaN превращается в null

Почему ключи в кавычках?

Потому что JSON создавался как универсальный формат для всех языков программирования, не только для JS. В других языках ключи без кавычек не поддерживаются
