## Примитивы vs объекты

В JS все данные делятся на две группы: примитивы и объекты. Они по-разному хранятся, копируются и сравниваются

---

### Примитивы

Примитивы - это простые типы данных. Всего 6 примитивов (кроме `symbol`):

- `number` - числа (`1`, `42`, `NaN`, `Infinity`)
- `string` - строки (`"hello"`, `'мир'`)
- `boolean` - `true` / `false`
- `null` - пустота (ничего)
- `undefined` - не определено

Примитивы **копируются по значению**. При присваивании создаётся независимая копия:

```javascript
let a = 5;
let b = a;   // b получает копию значения 5
b = 10;
console.log(a); // 5 - не изменилось
console.log(b); // 10
```

Примитивы **сравниваются по значению**:

```javascript
console.log(5 === 5);       // true
console.log("hi" === "hi"); // true
```

---

### Объекты (ссылочные типы)

Объекты - это составные типы: объекты, массивы, функции. Они **копируются по ссылке**. При присваивании переменные указывают на один и тот же объект в памяти

```javascript
let obj1 = { name: "Анна" };
let obj2 = obj1;   // obj2 теперь ссылается на тот же объект
obj2.name = "Борис";
console.log(obj1.name); // "Борис" - изменился и obj1!
```

Переменная `obj1` хранит не сам объект, а адрес в памяти, где этот объект лежит. Когда мы пишем `let obj2 = obj1`, копируется адрес, а не сам объект. Теперь `obj1` и `obj2` смотрят на один и тот же дом. Изменили что-то через `obj2` - `obj1` тоже видит изменения, потому что дом-то один

**Сравнение объектов**

Объекты сравниваются по ссылке, а не по содержимому. Два объекта с одинаковыми свойствами - разные объекты в памяти

```javascript
console.log({} === {});          // false - разные объекты в памяти
console.log([1, 2] === [1, 2]);  // false - разные массивы
```

Это как два одинаковых дома на разных улицах - они выглядят одинаково, но это разные здания. А вот если ссылка одна - тогда `true`:

```javascript
let arr = [1, 2];
let copy = arr;
console.log(arr === copy);       // true - одна и та же ссылка
```

Обе переменные указывают на один и тот же массив в памяти, поэтому они равны

---

### Как скопировать объект

**Поверхностная копия** (только первый уровень):

```javascript
let original = { a: 1, b: 2 };
let copy = Object.assign({}, original);
// или через spread: let copy = { ...original };
```

**Глубокая копия** (все уровни, включая вложенные объекты):

```javascript
let original = { a: 1, b: { c: 2 } };
let copy = JSON.parse(JSON.stringify(original));
copy.b.c = 99;
console.log(original.b.c); // 2 - исходный не изменился
```

**Задачи**

```javascript
// 1. Что выведет?
let x = "hello";
let y = x;
y = "world";
console.log(x);
console.log(y);
```

<details>
<summary>Ответ</summary>

`"hello"` и `"world"` - строки (примитивы) копируются по значению, `x` не изменился

</details>

```javascript
// 2. Что выведет?
let arr1 = [1, 2, 3];
let arr2 = arr1;
arr2.push(4);
console.log(arr1);
```

<details>
<summary>Ответ</summary>

`[1, 2, 3, 4]` - массивы копируются по ссылке, `arr1` и `arr2` указывают на один массив

</details>

```javascript
// 3. Что выведет?
let obj1 = { x: 10 };
let obj2 = { x: 10 };
console.log(obj1 === obj2);
```

<details>
<summary>Ответ</summary>

`false` - разные объекты в памяти, даже с одинаковым содержимым

</details>

---

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let a = { value: 1 };
let b = a;
b.value = 2;
b = { value: 3 };
console.log(a.value);
console.log(b.value);
```

<details>
<summary>Ответ</summary>

`2` и `3` - `b.value = 2` изменило общий объект. `b = { value: 3 }` переключило `b` на новый объект, `a` остался со старым

</details>

```javascript
// 5. ⭐ Что выведет?
function mutate(obj) {
    obj.name = "changed";
    obj = { name: "new" };
}

let user = { name: "original" };
mutate(user);
console.log(user.name);
```

<details>
<summary>Ответ</summary>

`"changed"` - `obj.name = "changed"` изменило исходный объект. `obj = { name: "new" }` переключило локальную переменную, не тронув `user`

**`obj = { name: "new" }`** - переключение **локальной** переменной obj на новый объект `obj`. До этого `obj` и `user` ссылались на один объект. После присвоения `obj` начинает указывать на **новый объект** в памяти, а `user` продолжает ссылаться на старый. Новый объект живёт только внутри функции и после её завершения исчезает. Поэтому `user.name` остался `"changed"`
</details>
