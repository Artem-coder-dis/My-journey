## trim

`trim()` - убирает пробелы в начале и конце строки. Не трогает пробелы внутри строки. Возвращает новую строку, исходная не меняется

```javascript
let str = "   Hello World   "
console.log(str.trim()) // "Hello World" - без пробелов по краям
console.log(str)        // "   Hello World   " - исходная не изменилась
```

**Где пригодится:**

- Очистка ввода из форм (пользователи часто ставят лишние пробелы)
- Валидация перед отправкой на сервер
- Нормализация данных перед сравнением

**Пример с формой:**

```javascript
let input = "   user@mail.ru   "
let email = input.trim()
console.log(email) // "user@mail.ru" - готово к проверке
```

**Валидация перед отправкой на сервер:**

```javascript
let email = "   user@mail.ru   "
if (email.trim() === "") {
    console.log("Email обязателен")
} else {
    console.log("Отправляем на сервер: " + email.trim())
}
```

**Нормализация данных перед сравнением:**

```javascript
let input1 = "  Анна"
let input2 = "Анна  "
if (input1.trim() === input2.trim()) {
    console.log("Пользователь найден")
} else {
    console.log("Пользователь не найден")
}
```

&nbsp;

**Разбор задачи с циклом и условием:**

Дана строка с пробелами по краям. Нужно проверить, осталось ли в ней что-то после очистки. Если строка пустая или состоит только из пробелов - вывести "Пусто", иначе - очищенную строку

```javascript
let input = "      "

if (input.trim() === "") {
    console.log("Пусто")
} else {
    console.log(input.trim())
}
```

Сначала `trim()` убирает пробелы по краям. Если после этого строка стала пустой (`""`), значит, исходная состояла только из пробелов. Тогда выводим `"Пусто"`. Иначе выводим очищенную строку

---

**Задачи**

```javascript
// 1. Напиши код (не функцию), который принимает строку с пробелами по краям и выводит её без пробелов
// "   hello   " → "hello"
```

<details>
<summary>Ответ</summary>

```javascript
const str = "   hello   "
console.log(str.trim())
```

</details>

```javascript
// 2. Напиши код, который проверяет, пустая ли строка после удаления пробелов по краям. Если пустая - выведи "Пусто", иначе - "Не пусто"
// "   " → "Пусто"
// "  hi  " → "Не пусто"
```

<details>
<summary>Ответ</summary>

```javascript
const str = "   "
if (str.trim() === "") {
    console.log("Пусто")
} else {
    console.log("Не пусто")
}
```

</details>

```javascript
// 3. Напиши функцию, которая принимает две строки, очищает их от пробелов по краям и возвращает true, если они равны, и false, если нет
// compareTrimmed("  hello", "hello  ") → true
// compareTrimmed("hello", "world") → false
```

<details>
<summary>Ответ</summary>

```javascript
function compareTrimmed(a, b) {
    return a.trim() === b.trim()
}
```

</details>

```javascript
// 4. ⭐ Напиши код, который принимает строку и выводит её длину после удаления пробелов по краям
// "   hello   " → 5
```

<details>
<summary>Ответ</summary>

```javascript
const str = "   hello   "
console.log(str.trim().length)
```

</details>

```javascript
// 5. ⭐ Напиши функцию, которая принимает строку и возвращает true, если после удаления пробелов по краям её длина больше 3
// longerThanThree("   hello   ") → true
// longerThanThree("   hi   ") → false
```

<details>
<summary>Ответ</summary>

```javascript
function longerThanThree(str) {
    return str.trim().length > 3
}
```

</details>

```javascript
// 6. ⭐ Напиши функцию, которая принимает строку и возвращает количество пробелов в начале и конце. Пробелы внутри не считаем
// countEdgeSpaces("   hello   ") → 6
// countEdgeSpaces("hello") → 0
```

<details>
<summary>Ответ</summary>

```javascript
function countEdgeSpaces(str) {
    return str.length - str.trim().length
}
```

</details>
