## indexOf

`indexOf` - ищет подстроку в строке и возвращает индекс (позицию) первого вхождения. Если не найдено - возвращает `-1`

```javascript
let str = "Hello World"
console.log(str.indexOf("World")); // 6 - "World" начинается с индекса 6
console.log(str.indexOf("JS"));    // -1 - "JS" не найдено
console.log(str.indexOf("o"));     // 4 - первое "o" на индексе 4
```

**Второй аргумент - с какой позиции начинать поиск:**

```javascript
let str = "Hello World";
console.log(str.indexOf("o", 5)); // 7 - ищем "o" начиная с индекса 5
```

**Где пригодится:**

- Проверить, есть ли подстрока (если `!== -1`)
- Найти позицию символа для обрезки строки
- Парсинг данных (найти разделитель и разрезать строку)
- Проверка расширения файла

**Пример - проверка наличия:**

```javascript
let email = "user@mail.ru";
if (email.indexOf("@") !== -1) {
    console.log("Email корректен");
} else {
    console.log("Нет символа @");
}
```

**Пример - обрезка строки до разделителя:**

```javascript
let filename = "script.js";
let dotIndex = filename.indexOf(".");
let name = filename.slice(0, dotIndex);
console.log(name); // "script"
```

**Задача.** Нужно былоо написать функцию, которая принимает URL и возвращает домен (часть между `://` и первым `/`)

```javascript
function getDomain(url) {
    const start = url.indexOf("://") + 3;
    const end = url.indexOf("/", start);
    return url.slice(start, end);
}

console.log(getDomain("https://github.com/user")); // "github.com"
console.log(getDomain("http://example.com/path")); // "example.com"
```

**Разбор:**

1. `url.indexOf("://")` - находим позицию двоеточия в `://`. Для `"https://..."` это индекс 5
2. `+ 3` - сдвигаемся на 3 символа (длина `://`), чтобы встать на начало домена. Индекс 5 + 3 = 8 - это начало `"github.com"`
3. `url.indexOf("/", start)` - ищем первый `/` после начала домена. Это конец домена
4. `url.slice(start, end)` - вырезаем домен от начала до первого `/`

**Нюанс с `+ 3`:**

`+ 3` должно быть **за скобками** `indexOf`, а не внутри. `indexOf("://" + 3)` искало бы строку `"://3"`, а `indexOf("://") + 3` сначала находит позицию `"://"`, потом прибавляет 3 к индексу

```javascript
// 4. ⭐ Напиши код, который принимает строку и выводит позицию второго вхождения буквы "o"

```

<details>

```javascript
let str = "Hello World";
let first = str.indexOf("o");
let second = str.indexOf("o", first + 1);
console.log(second);
```

</details>

```javascript
// 5. ⭐ Напиши функцию, которая принимает строку и символ, и возвращает позицию второго вхождения этого символа. Если второго вхождения нет - вернуть -1
// secondIndex("hello", "l") → 3
// secondIndex("JavaScript", "a") → 3
// secondIndex("hello", "x") → -1
```

<details>
<summary>Ответ</summary>

```javascript
function secondIndex(str, char) {
    let first = str.indexOf(char)
    if (first === -1) return -1
    return str.indexOf(char, first + 1)
}

console.log(secondIndex("hello", "l")) // 3
console.log(secondIndex("JavaScript", "a")) // 3
console.log(secondIndex("hello", "x")) // -1
```

</details>
