## includes

`includes` - это метод строк и массивов. Проверяет, содержится ли подстрока (или элемент) в строке (или массиве). Возвращает `true` или `false`

**Синтаксис:**

```javascript
строка.includes(подстрока, начальнаяПозиция(индекс));
массив.includes(элемент, начальнаяПозиция(индекс));
```

Второй аргумент (начальная позиция) необязателен. Если не указан - поиск с начала

**Примеры со строками:**

```javascript
let str = "JavaScript";

console.log(str.includes("Script")); // true
console.log(str.includes("script")); // false - регистр важен
console.log(str.includes(""));       // true - пустая строка есть везде
```

**Пример с начальной позицией:**

```javascript
let str = "Hello World";

console.log(str.includes("World", 6)); // true - "World" начинается с индекса 6
console.log(str.includes("World", 7)); // false - с индекса 7 уже нет "World"
```

**Примеры с массивами:**

```javascript
let arr = [10, 20, 30];

console.log(arr.includes(20));   // true
console.log(arr.includes(40));   // false
console.log(arr.includes("20")); // false - строгое сравнение, число 20 ≠ строка "20"
```

**Где пригодится:**

- Проверка наличия символа в email (`"@"`)
- Поиск запрещённых слов в тексте
- Проверка, есть ли элемент в массиве (перед добавлением, чтобы не дублировать)
- Валидация ввода (есть ли пробелы в пароле)

**Пример с проверкой email:**

```javascript
function isValidEmail(email) {
    if (!email.includes("@")) return false;
    return true;
}

console.log(isValidEmail("user@mail.ru")); // true
console.log(isValidEmail("usermail.ru"));  // false
```

Это учебный пример. В реальных задачах проверка строже (длина, домен, пробелы)

**Задачи**

```javascript
// 1. Что выведет?
let str = "JavaScript";
console.log(str.includes("Script"));
```

<details>
<summary>Ответ</summary>

`true` - `"JavaScript"` содержит `"Script"`

</details>

```javascript
// 2. Что выведет?
let str = "Hello World";
console.log(str.includes("world"));
```

<details>
<summary>Ответ</summary>

`false` - `includes` чувствителен к регистру, `"world"` с маленькой буквы нет

</details>

```javascript
// 3. Что выведет?
let str = "Hello";
console.log(str.includes(""));
```

<details>
<summary>Ответ</summary>

`true` - пустая строка считается содержащейся в любой строке

</details>

---

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let str = "abba";
console.log(str.includes("ab", 1));
console.log(str.includes("ba", 2));
console.log(str.includes("ba", 3));
```

<details>
<summary>Ответ</summary>

`false`, `true`, `false`

- `"ab"` с индекса 1: `"bba"` - `"ab"` нет → `false`
- `"ba"` с индекса 2: `"ba"` - есть → `true`
- `"ba"` с индекса 3: `"a"` - `"ba"` нет → `false`
</details>

```javascript
// 5. ⭐ Что выведет?
let str = "abc123";
console.log(str.includes(1));
console.log(str.includes("1"));
```

<details>
<summary>Ответ</summary>

`false` и `true` - `includes` не приводит типы. Число `1` не равно строке `"1"`. Ищет строго

</details>
