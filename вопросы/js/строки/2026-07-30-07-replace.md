## replace

`replace` - заменяет первую найденную подстроку на другую. Возвращает новую строку, исходная не меняется.

```javascript
let str = "Hello World"
console.log(str.replace("World", "JS")) // "Hello JS"
console.log(str) // "Hello World" - исходная не изменилась
```

**Замена только первого совпадения:**

```javascript
let str = "cat and cat"
console.log(str.replace("cat", "dog")) // "dog and cat" - только первый cat
```

**Чтобы заменить все совпадения - регулярное выражение с флагом g** (пока просто знай, что так можно)**:**

```javascript
let str = "cat and cat"
console.log(str.replace(/cat/g, "dog")) // "dog and dog"
```

**Где пригодится:**

- Форматирование текста (заменить запятые на точки)
- Очистка номера телефона (убрать скобки, пробелы, дефисы)
- Шаблоны (заменить `{name}` на реальное имя)
- Замена запрещённых слов

**Пример с шаблоном:**

```javascript
let template = "Привет, {name}!"
let result = template.replace("{name}", "Анна")
console.log(result) // "Привет, Анна!"
```

&nbsp;

**Регулярное выражение**

Чтобы удалить несколько разных символов сразу (скобки, пробелы, дефисы), используют регулярное выражение - специальный шаблон для поиска

```javascript
let str = "+7 (926) 123-45-67"
console.log(str.replace(/[\(\)\s\-]/g, "")) // "+79261234567"
```

Что здесь творится:
- `/.../g` - регулярное выражение, `g` значит «заменить все совпадения»
- `[...]` - любой символ из скобок
- `\(` - экранированная открывающая скобка
- `\)` - экранированная закрывающая скобка
- `\s` - любой пробельный символ (пробел, табуляция(Tab))
- `\-` - экранированный дефис

Второй аргумент `""` - пустая строка, то есть удаляем найденное

Пока не обязательно глубоко разбираться в регулярных выражениях - просто знай, что так можно убрать несколько символов за один вызов `replace`

**Почему мы ставим то `/`, то `\`?**

`/` — открывает и закрывает регулярное выражение. Внутри него уже идёт сам шаблон

`\` — это экранирование. Некоторые символы в регулярных выражениях имеют специальное значение (`(`, `)`, `[`, `]`, `-`, `.` и другие). Чтобы использовать их как обычный символ, перед ними ставят `\`

```javascript
/\(/  // ищем именно скобку "(", а не начало группы
/\-/  // ищем именно дефис "-", а не диапазон
/\./  // ищем именно точку ".", а не любой символ
```

- `(` - **скобка** (в регулярных выражениях это не просто скобка, а специальный знак, который начинает «группу» (объединяет часть выражения), но здесь она не нужна, поэтому экранируем)
- `-` - **дефис** (внутри `[...]` означает диапазон: `[a-z]` - все буквы от a до z, поэтому экранируем, чтобы был просто дефисом)
- `.` - **точка** (в регулярках означает «любой символ», поэтому экранируем, чтобы была именно точкой)

Есть ещё `[^...]` - означает «любой символ, КРОМЕ перечисленных». Например, `[^0-9]` - любой символ, кроме цифр.

**Задачи**

```javascript
// 1. Напиши код, который принимает строку и заменяет в ней все пробелы на дефисы
// "hello world js" → "hello-world-js"
```

<details>
<summary>Ответ</summary>

```javascript
let str = "hello world js"
console.log(str.replace(/ /g, "-"))
```

</details>

```javascript
// 2. Напиши функцию, которая принимает строку и возвращает её, заменив первое вхождение "js" на "JavaScript"
// replaceFirstJS("I love js and js") → "I love JavaScript and js"
```

<details>
<summary>Ответ</summary>

```javascript
function replaceFirstJS(str) {
    return str.replace("js", "JavaScript")
}

console.log(replaceFirstJS("I love js and js"))
```

</details>

```javascript
// 3. Напиши код, который принимает email и заменяет в нём домен "mail.ru" на "gmail.com"
// "user@mail.ru" → "user@gmail.com"
```

<details>
<summary>Ответ</summary>

```javascript
let email = "user@mail.ru"
console.log(email.replace("mail.ru", "gmail.com"))
```

</details>

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Напиши функцию, которая принимает строку и заменяет все цифры на символ "*"
// hideDigits("Мой номер: 123-45-67") → "Мой номер: ***-**-**"
```

<details>
<summary>Ответ</summary>

```javascript
function hideDigits(str) {
    return str.replace(/[0-9]/g, "*")
}

console.log(hideDigits("Мой номер: 123-45-67"))
```

</details>

```javascript
// 5. ⭐ Напиши функцию, которая принимает строку и заменяет все вхождения "kot" на "cat", а "sobaka" на "dog"
// translateAnimals("kot i sobaka") → "cat i dog"
```

<details>
<summary>Ответ</summary>

```javascript
function translateAnimals(str) {
    return str.replace(/kot/g, "cat").replace(/sobaka/g, "dog")
}

console.log(translateAnimals("kot i sobaka"))
```

</details>
