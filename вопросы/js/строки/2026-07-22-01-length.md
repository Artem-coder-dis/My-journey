## Свойство length

### Этап 1. Свойство length у строк

`length` - это свойство строки, которое возвращает количество символов в ней. Не метод, поэтому скобки не нужны

```javascript
let str = "Привет";
console.log(str.length); // 6
```

Считаются все символы: буквы, пробелы, цифры, знаки препинания

```javascript
console.log("Hello World".length);  // 11 (10 букв + 1 пробел)
console.log("12345".length);        // 5
console.log("Анна".length);         // 4
console.log("".length);             // 0 - пустая строка
```

**Где пригодится:**

- Проверка пустого ввода: `if (input.length === 0)`
- Валидация пароля: `if (password.length < 8)`
- Обрезка длинного текста: `if (text.length > 100)`
- Циклы по строке: `for (let i = 0; i < str.length; i++)`

**С циклом:**

```javascript
let str = "JS";
for (let i = 0; i < str.length; i++) {
    console.log(str[i]);
}
// "J", "S"
```

**Задачи**

```javascript
// 1. Что выведет?
let str = "Hello";
console.log(str.length);
```

<details>
<summary>Ответ</summary>

`5`

</details>

```javascript
// 2. Что выведет?
let str = "";
console.log(str.length);
```

<details>
<summary>Ответ</summary>

`0` - пустая строка

</details>

```javascript
// 3. Что выведет?
let str = " ";
console.log(str.length);
```

<details>
<summary>Ответ</summary>

`1` - пробел это тоже символ

</details>

---

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let str = "Hello\nWorld";
console.log(str.length);
```

<details>
<summary>Ответ</summary>

`11` - `\n` считается за один символ (перенос строки)

</details>

```javascript
// 5. ⭐ Что выведет?
let str = "Привет";
console.log(str[0], str[str.length - 1]);
```

<details>
<summary>Ответ</summary>

`"П"`, `"т"` - первый и последний символы через индекс

&nbsp;

`str[0]` - указывает на 1-ый символ `"П"`

`[str.length - 1]` - это индекс последнего элемента (5)(индексы начинаются с 0, а не как символы с 1). добавляем перед ней `str` чтобы было понятно у чего берём длину и к чему обращаемся по индексу. Без `st` перед скобками JS не знает, **откуда** брать символ. `str[5]` - «из строки str дай символ 6». Просто `[5]` - непонятно, у чего брать. str указывает источник

</details>

### Этап 2. Свойство length у массивов

`length` у массивов работает так же, как у строк - возвращает количество элементов

```javascript
let arr = [10, 20, 30];
console.log(arr.length); // 3
```

Считаются все элементы: числа, строки, булевы, объекты, вложенные массивы

```javascript
console.log([1, "hello", true].length); // 3
console.log([].length);                 // 0 - пустой массив
console.log([[1, 2], [3, 4]].length);   // 2 - два вложенных массива
```

**Доступ к последнему элементу:**

Так же, как у строк - через `arr[arr.length - 1]`

```javascript
let arr = [10, 20, 30];
console.log(arr[arr.length - 1]); // 30 - последний элемент
```

**Где пригодится:**

- Проверка пустого массива: `if (arr.length === 0)`
- Перебор в цикле: `for (let i = 0; i < arr.length; i++)`
- Добавление в конец: `arr[arr.length] = новыйЭлемент`

**Добавление в конец:**

```javascript
let arr = [1, 2, 3];
arr[arr.length] = 4;
console.log(arr); // [1, 2, 3, 4]
```

`arr.length` = 3, значит `arr[3] = 4` - элемент добавляется в конец массива

Работает точно также как `push`, но через `length`. На практике всегда используют `push` - он короче и читается понятнее. А пример с `length` - учебный, просто, чтобы понять, как работает свойство

**Задачи**

```javascript
// 1. Что выведет?
let arr = [true, null, -10, NaN, undefined];
console.log(arr.length);
```

<details>
<summary>Ответ</summary>

`5` - любой элемент в массиве считается, независимо от значения

</details>

```javascript
// 2. Что выведет?
let arr = [];
console.log(arr.length);
```

<details>
<summary>Ответ</summary>

`0` - пустой массив

</details>

```javascript
// 3. Что выведет?
let arr = [1, 2, 3, 4];
console.log(arr[arr.length - 2]);
```

<details>
<summary>Ответ</summary>

`3` - предпоследний элемент

</details>

---

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let arr = ["a", "b", "c"];
arr[arr.length - 1] = "d";
console.log(arr);
```

<details>
<summary>Ответ</summary>

`["a", "b", "d"]` - заменяет последний элемент `"c"` на `"d"`. Не добавляет, а заменяет, потому что индекс 2 уже существует

</details>

```javascript
// 5. ⭐ Что выведет?
let arr = ["x", "y", "z"];
console.log(arr[arr.length]);
```

<details>
<summary>Ответ</summary>

`undefined` - `arr.length` = 3, но индексы 0, 1, 2. Элемента с индексом 3 не существует

То есть у массива `["x", "y", "z"]` длина **3**, индексы: 0 (`"x"`), 1 (`"y"`), 2 (`"z"`). Индекса 3 не существует - там ничего нет. Поэтому `arr[3]` возвращает `undefined`

</details>

### Этап 3: Нюансы length у массивов

Свойство `length` у массивов не только возвращает количество элементов, но и позволяет изменять массив

**Изменение длины**

Если присвоить `length` значение меньше текущего - массив обрезается. Лишние элементы удаляются

```javascript
let arr = [1, 2, 3, 4, 5];
arr.length = 3;
console.log(arr); // [1, 2, 3]
```

Если присвоить значение больше текущего - массив расширяется, новые элементы становятся `undefined`

```javascript
let arr = [1, 2];
arr.length = 5;
console.log(arr); // [1, 2, , , ]
console.log(arr[3]); // undefined
```

**Очистка массива**

Самый простой способ очистить массив - `arr.length = 0`

```javascript
let arr = [1, 2, 3];
arr.length = 0;
console.log(arr); // []
```

**Зачем нужна очистка массива:**

- Сбросить данные после выхода пользователя
- Очистить корзину после оформления заказа
- Сброс списка уведомлений после прочтения

Корзина товаров:

```javascript
let cart = ["Хлеб", "Молоко", "Сыр"];
console.log(cart); // ["Хлеб", "Молоко", "Сыр"]

// Пользователь оформил заказ — очищаем корзину
cart.length = 0;
console.log(cart); // [] — корзина пуста, можно наполнять заново
```

---

**Задачи**

```javascript
// 1. Что выведет?
let arr = [10, 20, 30];
arr.length = 2;
console.log(arr);
```

<details>
<summary>Ответ</summary>

`[10, 20]` - обрезали до 2 элементов

</details>

```javascript
// 2. Что выведет?
let arr = [1, 2, 3];
arr.length = 5;
console.log(arr[4]);
```

<details>
<summary>Ответ</summary>

`undefined` - массив расширился, новый элемент пустой

</details>

```javascript
// 3. Что выведет?
let arr = [5, 10, 15];
arr.length = 0;
arr.length = 3;
console.log(arr);
```

<details>
<summary>Ответ</summary>

`[ , , ]` (три пустых элемента) - очистили, потом расширили. Элементы не восстановились

</details>

---

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let arr = [1, 2, 3, 4];
arr.length = arr[arr.length - 1];
console.log(arr);
```

<details>
<summary>Ответ</summary>

`[1, 2, 3, 4]` - `arr.length - 1` = 3, `arr[3]` = 4, `arr.length = 4`. Ничего не изменилось, потому что длина 4 и была равна 4

</details>

```javascript
// 5. ⭐ Что выведет?
let arr = [1, 2, 3, 4, 5];
arr.length = arr.length - 2;
console.log(arr);
console.log(arr[arr.length - 1]);
```

<details>
<summary>Ответ</summary>

`[1, 2, 3]` и `3`.

`arr.length` было 5, `5 - 2 = 3`, `arr.length = 3` обрезало массив до трёх элементов. Осталось `[1, 2, 3]`. Последний элемент: `arr[2]` → `3`

</details>

**Итог:**

- `length` - свойство, которое возвращает количество символов (для строк) или элементов (для массивов)
- Последний элемент: `str[str.length - 1]`
- У массивов `length` можно изменять: обрезать (`arr.length = 2`), расширять (`arr.length = 5`), очищать (`arr.length = 0`)
- `arr[arr.length] = элемент` - добавление в конец (учебный приём, на практике используют `push`)
- Пустая строка или массив: `"".length` → `0`, `[].length` → `0`
