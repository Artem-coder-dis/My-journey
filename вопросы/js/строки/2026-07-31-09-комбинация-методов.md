## Комбинации методов строк

Большинство методов строк по-настоящему раскрываются при работе с DOM (DOM - это способ управлять HTML-страницей через JS, подробнее в разделе DOM) - когда пользователь вводит данные в форму, а ты их очищаешь, проверяешь, форматируешь и отправляешь. Пока мы работаем в консоли, но позже я постараюсь разобрать эти методы на реальных примерах

Решил добавить подсказки, в них только какие методы нужно использовать

---

```javascript
// 1. Напиши код, который принимает строку, убирает пробелы по краям и приводит к верхнему регистру
// "   hello world   " → "HELLO WORLD"
```

<details>
<summary>Подсказка</summary>

`trim()` и `toUpperCase()`

</details>

<details>
<summary>Ответ</summary>

```javascript
const str = "   hello world   ";
console.log(str.trim().toUpperCase());
```

</details>

```javascript
// 2. Напиши функцию, которая принимает email, приводит к нижнему регистру и возвращает true, если в нём есть "@"
// "User@Mail.Ru" → true
// "UserMail.ru" → false
```

<details>
<summary>Подсказка</summary>

`toLowerCase()` и `indexOf("@")`

</details>

<details>
<summary>Ответ</summary>

```javascript
function hasAt(email) {
    const lowered = email.toLowerCase();
    return lowered.indexOf("@") !== -1;
}

console.log(hasAt("User@Mail.Ru")); // true
console.log(hasAt("UserMail.ru")); // false
```

</details>

```javascript
// 7. Напиши функцию, которая принимает строку и возвращает "Да", если она начинается с "http", и "Нет", если нет
// "https://github.com" → "Да"
// "ftp://server.com" → "Нет"
```

<details>
<summary>Подсказка</summary>

`indexOf("http") === 0`

</details>

<details>
<summary>Ответ</summary>

```javascript
function startsWithHttp(str) {
    if (str.indexOf("http") === 0) {
        return "Да";
    }
    return "Нет";
}

console.log(startsWithHttp("https://github.com")); // "Да"
console.log(startsWithHttp("ftp://server.com")); // "Нет"
```

</details>

```javascript
// 9. Напиши функцию, которая принимает строку и символ, и возвращает true, если символ найден в строке, и false, если нет
// "hello", "e" → true
// "hello", "x" → false
```

<details>
<summary>Подсказка</summary>

`indexOf()` и проверка на `-1`

</details>

<details>
<summary>Ответ</summary>

```javascript
function hasChar(str, char) {
    return str.indexOf(char) !== -1;
}

console.log(hasChar("hello", "e")); // true
console.log(hasChar("hello", "x")); // false
```

</details>

// 10. Напиши код, который принимает строку, удаляет пробелы по краям, заменяет первое вхождение "JS" на "JavaScript" и выводит результат в верхнем регистре

<summary>Подсказка</summary>

const result = str.trim().replace("JS", "JavaScript").toUpperCase();
