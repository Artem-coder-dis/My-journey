## split

`split` - это метод строки, который разбивает её в массив по разделителю. Возвращает новый массив, исходная строка не меняется

```javascript
строка.split(разделитель);
```

**Простое разбиение по пробелу:**

```javascript
let str = "hello world js";
console.log(str.split(" ")); // ["hello", "world", "js"]
```

**По запятой:**

```javascript
let str = "apple,banana,grape";
console.log(str.split(",")); // ["apple", "banana", "grape"]
```

**По пустой строке (разбить на символы):**

```javascript
let str = "JS";
console.log(str.split("")); // ["J", "S"]
```

**Где пригодится:**

- Разбить строку на слова
- Разбить теги
- Превратить строку в массив для дальнейшей обработки

**Пример с тегами:**

```javascript
let tags = "js, react, css";
let arr = tags.split(", ");
console.log(arr); // ["js", "react", "css"]
```

&nbsp;

**Задача.** Дан список чисел через запятую, в котором есть пропущенное значение. Нужно разбить строку в массив и понять, что окажется на месте пропуска

```javascript
let str = "1,2,,4,5";
let arr = str.split(",");
console.log(arr); // ["1", "2", "", "4", "5"]
console.log(arr.length); // 5
console.log(arr[2]); // ""
```

Между `2` и `4` две запятые подряд - это пустой элемент. `split` не пропускает его, а создаёт пустую строку. Поэтому `arr` = `["1", "2", "", "4", "5"]`, длина 5, а `arr[2]` = `""` (пустая строка)

---

**Задачи**

```javascript
// 1. Что выведет?
let str = "a b c";
console.log(str.split(" "));
```

<details>
<summary>Ответ</summary>

`["a", "b", "c"]` - разбили по пробелу

</details>

```javascript
// 2. Что выведет?
let str = "hello";
console.log(str.split(""));
```

<details>
<summary>Ответ</summary>

`["h", "e", "l", "l", "o"]` - разбили по пустой строке, каждый символ стал элементом массива

</details>

```javascript
// 3. Что выведет?
let str = "one,two,three";
console.log(str.split(","));
```

<details>
<summary>Ответ</summary>

`["one", "two", "three"]` - разбили по запятой

</details>

---

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let str = "   hello   world   ";
console.log(str.split(" "));
```

<details>
<summary>Ответ</summary>

`["", "", "", "hello", "", "", "world", "", "", ""]` - множественные пробелы создают пустые строки в массиве. Каждый пробел - разделитель, а между ними пустота

</details>

```javascript
// 5. ⭐ Что выведет?
let str = "apple,banana,grape";
console.log(str.split(",", 2));
```

<details>
<summary>Ответ</summary>

`["apple", "banana"]` - второй аргумент `split` ограничивает количество элементов в результате. Взяли только первые 2

</details>
