## Замыкания

На момент написания этого поста я сегодня завершил раздел объектов и начал повторение всего пройденного материала, и до сих пор не понимал, что такое замыкания, хоть и решал задачи с ними

Чтобы лучше понять тему, рекомендую изучать её после базового понимания функций (объявление, вызов, параметры, return), и потом можно будет идти к замыканиям

Замыкание - это когда функция запоминает переменные из того места, где была создана, и может использовать их позже, даже если это место уже отработало и исчезло

Звучит сложно, но на примере проще

**Пример 1. Без замыкания**

```javascript
function greet() {
    let name = "Анна";
    return "Привет, " + name;
}

console.log(greet()); // "Привет, Анна"
console.log(name);    // Ошибка! name не видна снаружи
```

`name` существует только пока работает `greet()`. После вызова `name` исчезает. Всё логично

**Пример 2. Замыкание**

```javascript
function createGreet() {
    let name = "Анна";
    
    return function() {
        return "Привет, " + name;
    }
}

const greet = createGreet();
console.log(greet()); // "Привет, Анна"
```

`createGreet()` отработала и завершилась. Но `name` не исчез! Внутренняя функция `return function() {...}` запомнила `name` и держит его. Это и есть замыкание - функция «замкнула» в себе переменную из внешней области

**Как это работает:**

- Вызвали `createGreet()` - создалась переменная `name = "Анна"`
- `createGreet` вернула внутреннюю функцию
- Внутренняя функция запомнила `name` из `createGreet`
- `createGreet` завершилась, но `name` живёт, потому что внутренняя функция на неё ссылается
- Вызываем `greet()` - внутренняя функция всё ещё видит `name`

Возможно, всё ещё непонятно и это нормально, ведь я тоже с трудом понял

У меня возникали вопросы:

**1. Какая разница в примере 1 и 2, вывод же тот же**

Разница не в выводе, а в том, когда вызывается функция и что происходит с переменной после

```javascript
function greet() {
    let name = "Анна";
    return "Привет, " + name;
}

console.log(greet()); // "Привет, Анна"
```

В первом примере `greet()` вызвали - она отработала, вернула строку, закрылась. Переменная `name` умерла. Всё. Её больше нет. При следующем вызове `greet()` создастся новая `name`, но старая исчезла

```javascript
function createGreet() {
    let name = "Анна";
    
    return function() {
        return "Привет, " + name;
    }
}

const greet = createGreet(); // createGreet отработала и ЗАВЕРШИЛАСЬ
console.log(greet()); // "Привет, Анна" - но как? name же должна была исчезнуть
```

Во втором примере `createGreet()` вызвали один раз. Она отработала, завершилась. По логике `name` должна исчезнуть. Но `name` не исчезла, потому что внутренняя функция `return function() {...}` запомнила её и держит

**2. Ну как исчезла? как было name = анна так и осталось анной. как же она удаляется если при следующем вызове всё равно тот же самый вывод?**

Потому что при следующем вызове `greet()` создаётся новая переменная `name` со значением `"Анна"`. Старая удалилась, новая создалась - но значение одно и то же, поэтому вывод одинаковый

Представь: ты испёк пирог, съел, тарелка пустая. Через час испёк такой же пирог - он выглядит так же, но это новый пирог, не тот же самый. Старого уже нет

В примере 1: каждый вызов `greet()` - это новый пирог. Старый исчез, новый создался

В примере 2: `createGreet()` испекла пирог один раз. И он НЕ исчез. Внутренняя функция держит этот самый первый пирог и никому не отдаёт. Сколько ни вызывай `greet()` - пирог тот же самый, не новый

**3. Ну а какая разница в этом если и там и там один и тот же ответ при вызове?**

И вот разница появляется, когда переменная меняется

**Пример 3 (без замыкания):**

```javascript
function greet() {
    let count = 0;
    count++;
    return count;
}

console.log(greet()); // 1
console.log(greet()); // 1
console.log(greet()); // 1 - каждый раз новая count, всегда сбрасывается
```

**Пример 4 (замыкание):**

```javascript
function createGreet() {
    let count = 0;
    
    return function() {
        count++;
        return count;
    }
}

const greet = createGreet();
console.log(greet()); // 1
console.log(greet()); // 2
console.log(greet()); // 3 - count не сбрасывается, живёт в замыкании
```

Вот теперь разница очевидна. С замыканием переменная накапливается. Без замыкания - каждый раз новая и сбрасывается

**То есть замыкание это просто функция внутри функции?**

Нет. Функция внутри функции - это вложенная функция. А замыкание - это когда внутренняя функция запоминает переменные из внешней и держится за них после того, как внешняя функция завершилась

Если внутренняя функция не использует переменные внешней - это просто вложенность, не замыкание

Если внутренняя функция использует переменные внешней и возвращается наружу - это замыкание

Коротко: вложенная функция + использование переменных внешней + возврат наружу = замыкание. Все три условия

**Ещё 1 момент который нужно разобрать, это независимые переменные**

```javascript
function createMultiplier(n) {
    return function(x) {
        return x * n;
    }
}

const double = createMultiplier(2);
const triple = createMultiplier(3);

console.log(double(4)); // 8 (2 * 4)
console.log(triple(4)); // 12 (3 * 4)
```

Каждый вызов `createMultiplier` создал своё замыкание со своим `n`. `double` помнит `n = 2`, `triple` помнит `n = 3`. Они независимы - изменение одной не повлияет на другую

Вывод: 1

**Задача 4.** Что выведет код и почему:

```javascript
let x = 10;
function outer() {
    return function() {
        console.log(x);
    }
}
const fn = outer();
fn();
x = 20;
fn();
```

<details>
<summary>Ответ</summary>

Вывод: 10 20

Тут уже всё благодаря работе области видимости
Сначала переменная `x = 10`, в функции `function()` вывод в консоль `x`, `x` не находит на своём уровне (вложенной/внутренней функции) и идёт выше во внешнюю функцию, там тоже не находит и тогда идёт в глобальную область видимости где `x = 10`

Далее мы переприсваиваем `x` и он становится равен 20, проходит та же операция, только `x` уже не 10, а 20

</details>
