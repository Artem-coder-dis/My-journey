## Поиск и изменение элементов в DOM

DOM позволяет находить HTML-элементы на странице через JS и что-то с ними делать. Основные методы

**querySelector** - найти первый подходящий элемент

```javascript
const title = document.querySelector("h1"); // первый h1 на странице
const button = document.querySelector(".btn"); // первый элемент с классом btn
const header = document.querySelector("#header"); // элемент с id header
```

**Что за document?**

`document` - это встроенный объект браузера, который представляет всю HTML-страницу. Через него JS получает доступ к элементам на странице. Появляется автоматически в браузере, не нужно его создавать или подключать


**querySelectorAll** - найти все подходящие элементы

```javascript
const allParagraphs = document.querySelectorAll("p"); // все абзацы
const allButtons = document.querySelectorAll(".btn"); // все элементы с классом btn
```

`querySelectorAll` возвращает NodeList - коллекцию элементов. Она похожа на массив: у неё есть `length`, по ней можно пройти циклом `for...of`, но у неё нет методов массива типа `map` или `filter`:

```html
<ul>
    <li>Яблоко</li>
    <li>Груша</li>
    <li>Банан</li>
</ul>
```

```javascript
const items = document.querySelectorAll("li");
for (let item of items) {
    console.log(item.textContent);
}

// Вывод в консоль:
// "Яблоко"
// "Груша"
// "Банан"
```

> **Если написать querySelectorAll("") или просто букву/слово не относящееся к тегам в HTML?**

Если передать в `querySelectorAll` селектор, которого нет на странице, он вернёт пустую коллекцию (NodeList длиной 0). Ошибки не будет

```javascript
const result = document.querySelectorAll(".несуществующийКласс");
console.log(result); // NodeList []
console.log(result.length); // 0
```

Если передать просто слово без точки, решётки или тега - например `querySelectorAll("hello")` - JS будет искать тег `<hello>`. Такого тега в HTML нет, поэтому тоже вернёт пустую коллекцию. Ошибки не будет

`querySelectorAll("")` с пустой строкой - выбросит ошибку `SyntaxError`, потому что пустой селектор недопустим

**textContent** - свойство DOM-элемента, которое хранит его текстовое содержимое. Можно читать и менять

```javascript
const el = document.querySelector("h1");

// Прочитать текст
console.log(el.textContent); // "Мой сайт"

// Заменить текст
el.textContent = "Новый заголовок";
console.log(el.textContent); // "Новый заголовок"
```

Меняется и исходная переменная, и текст, отображаемый на странице

```html
<p class="first">Первый</p>
<!-- после выполнения JS станет <p class="first">Изменено</p> -->
```

```javascript
const edit = document.querySelector(".first");

edit.textContent = "изменено";
console.log(edit.textContent); // "Изменено"
```

После изменения текст на странице обновится. Это основной способ работать с текстом внутри элементов

**getElementById** - найти по id (быстрее, но менее гибко)

```javascript
const main = document.getElementById("main"); // элемент с id main
```

**Почему менее гибко?**

`getElementById` работает быстрее, потому что ищет только по id (а `querySelector` может искать по любому селектору - классу, тегу, атрибуту). Но `getElementById` менее гибкий - им нельзя найти элемент по классу или по сложному селектору, только по id

```javascript
// getElementById - только по id
const el = document.getElementById("btn");

// querySelector - по любому селектору
const el = document.querySelector("#btn");   // по id
const el = document.querySelector(".text");  // по классу
const el = document.querySelector("div p");  // p внутри div
```

На практике чаще используют `querySelector` из-за гибкости, а `getElementById` - когда точно знаешь id и нужно чуть быстрее. Разница в скорости незаметна для обычных страниц

**Что такое сложный селектор?**

Это селектор, который состоит из нескольких частей, чтобы найти конкретный элемент

```javascript
// p с классом text
document.querySelector("p.text");

// li внутри ul с id menu
document.querySelector("#menu li");

// div > p (только прямые дочерние элементы)
document.querySelector("div > p");

// input с типом email
document.querySelector("input[type='email']");
```
