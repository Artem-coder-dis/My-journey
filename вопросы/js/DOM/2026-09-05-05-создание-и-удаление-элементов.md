### Этап 1. Изучение методов

**createElement**

`createElement` - создаёт новый элемент в памяти, но на страницу его не добавляет. Элемент как бы висит в воздухе, пока мы его куда-нибудь не вставим

```javascript
const newParagraph = document.createElement("p");
newParagraph.textContent = "Новый абзац";
```

Создали `<p>`, дали ему текст. Но на странице его пока нет

Можно сразу добавить класс:

```javascript
newParagraph.classList.add("highlight");
```

Или задать стиль:

```javascript
newParagraph.style.color = "red";
```

**Создать несколько элементов в цикле:**

```javascript
for (let i = 1; i <= 3; i++) {
    const li = document.createElement("li");
    li.textContent = "Элемент " + i;
}
```

Создали три `<li>`, но они всё ещё не на странице. Для этого нужен `append`

**append/prepend**

`append` - добавляет созданный элемент на страницу в конец указанного родителя

```javascript
document.body.append(newParagraph);
```

Теперь элемент появился на странице в конце `<body>`.

Визуально это как дописать новый тег в конец HTML перед закрывающим тегом родителя. Элементы добавляются сверху вниз в том порядке, в котором ты их добавляешь

Можно добавлять не только в `body`:

```javascript
document.querySelector("ul").append(li);        // в конец списка
document.querySelector(".container").append(p); // в конец блока
```

`append` всегда добавляет в конец. Для добавления в начало есть `prepend`:

```javascript
list.prepend(newItem); // в начало списка
```

Можно вкладывать один элемент в другой:

```javascript
const paragraph = document.createElement("p");
const input = document.createElement("input");
paragraph.append(input);
document.body.append(paragraph);
```

Получится `<p><input></p>`

То есть 

1. Мы создаём сначала `paragraph` - пустой `<p></p>`, он в памяти
2. Создали `input` - пустой `<input>`, тоже в памяти
3. `paragraph.append(input)` - вложили `input` ВНУТРЬ `paragraph`. Теперь `paragraph` выглядит как `<p><input></p>`, но всё ещё не на странице
4. `document.body.append(paragraph)` - добавили `paragraph` вместе с его содержимым на страницу. На странице появилось `<p><input></p>`

**remove**

`remove` - удаляет элемент со страницы

```javascript
const firstLi = document.querySelector("li");
firstLi.remove();
```

Удалили первый `<li>` со страницы. Элемент исчезает полностью

Можно удалить созданный ранее элемент:

```javascript
const item = document.querySelector("li");
item.remove();
```

Или удалить несколько элементов в цикле:

```javascript
const items = document.querySelectorAll("li");
for (let item of items) {
    item.remove();
}
```

Удалили все `<li>` со страницы

Моя **первая** задача - при клике на кнопку "Добавить" добавляй новый li с текстом "Новый элемент" в конец списка

```html
<ul id="list">
    <li>Первый</li>
    <li>Второй</li>
    <li>Третий</li>
</ul>

<button id="add">Добавить</button>
<button id="remove">Удалить</button> <!-- это для второй задачи -->
```

Сначала я написал так

```javascript
const addButton = document.querySelector("#add");
const newItem = document.createElement("li");

addButton.addEventListener("click", function() {
    newItem.textContent = "Новый элемент";
    document.body.append(newItem)
})
```

Но тут было пару ошибок:

Первая: `document.body.append(newItem)`

Я добавлял новый `li` в конец `body`, а не в список `<ul>`. Визуально элемент мог появиться где-то после списка или вообще не туда, куда нужно. Правильно добавлять в `list` - тот самый `ul`, с которым работаем

Вторая: элемент создан до обработчика

`const newItem = document.createElement("li")` стоит снаружи `addEventListener`. Это значит, что элемент создаётся один раз при загрузке страницы. При каждом клике я не создаю новый элемент, а просто перезаписываю текст у одного и того же

Визуально это выглядело бы так: первый клик - появился один `li`, второй клик - новый не добавился, а у старого просто обновился текст. Поэтому `createElement` должен быть внутри обработчика, чтобы при каждом клике создавался новый `li`

**Как правильно:**

```javascript
const addButton = document.querySelector("#add");
const list = document.querySelector("#list");

addButton.addEventListener("click", function() {
    const newItem = document.createElement("li"); // создаю новый li при каждом клике
    newItem.textContent = "Новый элемент";
    list.append(newItem); // добавляю в список, а не в body
});
```

**Вторая** задача. При клике на кнопку "Удалить" удаляй последний li из списка

HTML тот же. Первое решение:

```javascript
const deleteButton = document.querySelector("#remove");

deleteButton.addEventListener("click", function() {
    newItem.remove() // тут я обращался к константе из прошлого задания где мы создавали li
})
```

Но проблема в том, что `newItem` не определён в этом коде, он был внутри обработчика прошлого задания

Правильное решение такое:

```javascript
const removeButton = document.querySelector("#remove");
const list = document.querySelector("#list");

removeButton.addEventListener("click", function() {
    const items = list.querySelectorAll("li"); // Находим все li внутри списка
    if (items.length > 0) { // проверка, чтобы не пытаться удалить из пустого списка
        const lastItem = items[items.length - 1]; // берём последний
        lastItem.remove(); // и удаляем его
    }
});
```

Можно короче:

```javascript
removeButton.addEventListener("click", function() {
    const lastItem = list.lastElementChild;
    
    if (lastItem) {
        lastItem.remove();
    }
});
```

`list.lastElementChild` - берём последний элемент списка. Этот метод будем проходить позже, но он интуитивно понятный и подходит для этой задачи

В условии, если `lastItem` (последний элемент) существует, проверка пропускает удаление. Если список пуст - `lastItem` будет `null`, условие не сработает, ошибки не будет

**Третья** задача. При клике на кнопку "Удалить" удаляй 2 последних li из списка

```javascript
const deleteButton = document.querySelector("#remove");
const list = document.querySelector("#list");

deleteButton.addEventListener("click", function() {
    const items = list.querySelectorAll("li");

    for (let i = 0; i < 2; i++) {
        const lastItem = items[items.length - 1 - i];
        if (lastItem) {
            lastItem.remove();
        }
    }
})
```

1. Находим кнопку и список по id
2. Вешаем обработчик click на кнопку
3. `list.querySelectorAll("li")` - получаем коллекцию всех `li` внутри списка. Например, `["Первый", "Второй", "Третий"]`
4. Цикл `for (let i = 0; i < 2; i++)` - выполняем две итерации, чтобы удалить два элемента
5. `items[items.length - 1 - i]` - находим последний элемент

> Подробнее что происходит на шагах 4 и 5:
>
> `i < 2` - цикл выполнится ровно два раза: при `i = 0` и при `i = 1`
>
> **Как вычисляется индекс с конца:**
>
> У массива из 3 элементов индексы: `0, 1, 2`. Последний индекс - `2`
>
> Формула `items.length - 1` даёт последний индекс: `3 - 1 = 2`
>
> А формула `items.length - 1 - i` сдвигает этот индекс назад на `i` шагов
>
> - `i = 0`: `3 - 1 - 0 = 2` - последний
> - `i = 1`: `3 - 1 - 1 = 1` - предпоследний
>
> Цикл просто два раза подставляет растущее `i` в формулу `length - 1 - i`. А формула уже устроена так, что при увеличении `i` индекс идёт от конца к началу
>
> `i < 2` - это «сделай два шага». А какой именно индекс брать на каждом шаге - решает `length - 1 - i`. Цикл даёт `i`, формула превращает его в нужный индекс

6. `if (lastItem)` - проверяем, что элемент существует. Если список уже пуст или в нём меньше двух элементов - ошибки не будет или удалится один элемент
7. `lastItem.remove()` - удаляем найденный элемент

**Что происходит при клике:**

- Первый проход цикла: удаляется "Третий"
- Второй проход: удаляется "Второй"
- Остаётся только "Первый"

```javascript
const container = document.querySelector("#container");
const createListButton = document.querySelector("#createList");
const addItemButton = document.querySelector("#addItem");
let currentList = null;

createListButton.addEventListener("click", function() {
    currentList = document.createElement("ul");
    container.append(currentList);
});

addItemButton.addEventListener("click", function() {
    if (currentList) {
        const newItem = document.createElement("li");
        newItem.textContent = "Элемент";
        currentList.append(newItem);
    }
});
```

**Что происходит:**

1. Находим контейнер `div` и две кнопки по id
>
> Контейнер `div` позволяет держать структуру под контролем: мы точно знаем, где окажется список, и можем стилизовать этот блок отдельно. Поэтому в задаче используем `container.append(currentList)`, а не `document.body.append(currentList)`
2. `let currentList = null` - переменная, в которой пока ничего нет. Сюда сохраним созданный список

> **Зачем переменная объявлена снаружи, а не внутри обработчика:**
>
> Если бы мы написали `const currentList = document.createElement("ul")` внутри обработчика первой кнопки, то эта переменная жила бы только там. После завершения обработчика она исчезла бы, и вторая кнопка не смогла бы к ней обратиться
>
> Поэтому `currentList` объявлена снаружи - на уровне, доступном обоим обработчикам. Первая кнопка кладёт в неё созданный список, вторая - читает из неё и добавляет элементы. Обе кнопки работают с одной общей переменной

> **Почему `currentList = null`:**
>
> Пока пользователь не нажал первую кнопку, списка нет. `null` означает «пусто». После создания списка переменная хранит ссылку на него, и вторая кнопка знает, куда добавлять элементы

3. Первая кнопка `createListButton`:
   - при клике создаёт новый `ul` через `createElement`
   - сохраняет его в `currentList`
   - добавляет в контейнер `div`, а не в `body`

> **Почему список добавляем в `div`, а не в `body`:**
>
> В реальном проекте элементы добавляют в конкретный блок страницы, так список появится внутри нужного контейнера, а не в конец всего документа. Если добавлять в `body`, список появится в самом низу страницы, где его могут не заметить или он перемешается с другими элементами

> **Почему `container.append`, а не `document.container.append`:**
>
> `container` - это наша переменная, в которой лежит найденный `div`. Обращаемся к ней напрямую: `container.append(...)`
>
> `document.container` - бессмыслица. `document` - объект страницы, он не знает про нашу переменную. `document` нужен только для поиска элементов (`document.querySelector`), а найденный элемент мы сохраняем в переменную и дальше работаем с ней без `document`

4. Вторая кнопка `addItemButton`:
Проверяет `if (currentList)` - существует ли список

> **Зачем проверка `if (currentList)`:**
>
> Если нажать "Добавить элемент" до создания списка - `currentList` всё ещё `null`, условие ложно, ничего не произойдёт. Защита от ошибки

   - если да - создаёт новый `li`, даёт текст `"Элемент"`, добавляет в `currentList`

В задачах этого этапа встречается то, о чём не было сказано в первом этапе

**`append(несколькоЭлементов)`** - можно добавить сразу несколько элементов через запятую:

```javascript
newDiv.append(newPar, delButton); // добавили и абзац, и кнопку разом
```

**Массив для хранения элементов.** Когда нужно помнить все созданные элементы, их сохраняют в массив:

```javascript
let divs = [];       // массив
divs.push(newDiv);   // добавили
divs.pop();          // забрали последний
```

Зачем создавать массив? Затем, чтобы помнить, какие div-ы мы создали. Без массива кнопка «Удалить последний» не знает, что удалять - DOM не хранит порядок специально

Массив `divs` - это наша память. При создании пушим в него новый div, при удалении `pop()` забирает последний. Так мы всегда знаем, какой div был создан последним, даже после десяти кликов

Если бы мы хранили в `let lastDiv` - переменная указывала бы только на последний, а предыдущие забылись бы. А массив хранит все по порядку. `pop()` достаёт именно последний

**Вложенные обработчики**

Внешний обработчик срабатывает по клику, например, на кнопку «Добавить» - он создаёт карточку и вешает внутренний обработчик на её кнопку. Внутренний сработает позже, когда кликнут по другой кнопке, например, «Удалить»

Они не конфликтуют: один слушает кнопку «Добавить», второй - кнопку внутри карточки. Вложенность здесь - это способ привязать обработчик к только что созданному элементу. С таким подходом ты будешь сталкиваться в большинстве задач, где элементы создаются динамически (создаются в процессе работы страницы, через JS)

```javascript
        newDiv.remove(); // удаляем именно этот div
    });

    newDiv.append(newPar, deleteButton); // в новый div (карточку) добавляем абзац и кнопку
    container.append(newDiv); // добавляем карточку в контейнер
});
```

> **Почему кнопка «Удалить» удаляет именно свою карточку**
> 
> Когда кнопка создаётся внутри обработчика «Добавить», она запоминает свой `newDiv`. Это замыкание
>
> Кликнули по «Добавить» - создался `newDiv`, а внутри него кнопка `delButton`. На эту кнопку повесили обработчик, который вызывает `newDiv.remove()`. JavaScript запомнил, какой именно `newDiv` был рядом с этой кнопкой
>
> Кликнули по «Добавить» ещё раз - создался ДРУГОЙ `newDiv` и ДРУГАЯ `delButton`. У каждой кнопки своё замыкание: первая помнит первый `newDiv`, вторая - второй
>
> Поэтому если нажать «Удалить» на первой карточке - удалится первая. На второй - вторая. Кнопки не перепутаются, хотя код одинаковый
>
> Если бы кнопки не имели замыкания и обе смотрели на одну общую переменную - обе удаляли бы последнюю созданную карточку. Замыкание решает эту проблему: каждая кнопка привязана к своей карточке намертво

```javascript
const countButton = document.querySelector("#count"); // находим кнопку "Счётчик"
const removeButton = document.querySelector("#removeLast"); // кнопка "Удалить последний"
const container = document.querySelector("#container"); // контейнер для div-ов
let divs = []; // массив, где будем хранить все созданные div-ы (про него писал выше)

countButton.addEventListener("click", function() { // при клике на "Счётчик"
    const newDiv = document.createElement("div"); // создаём новый div
    newDiv.textContent = "1"; // кладём в него стартовое число 1

    newDiv.addEventListener("click", function() { // при клике на сам div

    }
```

```javascript
// При нажатии Enter в поле - текст из поля становится новым li в списке, поле очищается
```

```javascript
const poleVvoda = document.querySelector("#pole"); // находим поле ввода
const list = document.querySelector("#spisok"); // список ul

poleVvoda.addEventListener("keydown", function(item) { // при нажатии клавиши в поле
    if (item.key === "Enter") { // если нажата клавиша Enter
        if (poleVvoda.value !== "") { // и поле не пустое
            const newLi = document.createElement("li"); // создаём новый li
            newLi.textContent = poleVvoda.value; // кладём в него текст из поля

            newLi.addEventListener("click", function() { // при клике на li
                newLi.classList.toggle("crossOut"); // переключаем зачёркивание
            });

            newLi.addEventListener("dblclick", function() { // при двойном клике на li
                newLi.remove(); // удаляем li
            });

            list.append(newLi); // добавляем li в список
            poleVvoda.value = ""; // очищаем поле ввода
        }
    }
});
```

**Конфликт `click` и `dblclick`**

При двойном клике браузер сначала считает это двумя одиночными кликами, а потом - двойным. Поэтому на одном элементе сработают оба обработчика:

1. Первый `click` - li зачеркнулся
2. Второй `click` - li снова обычный (toggle сработал обратно)
3. `dblclick` - li удалился

Визуально ты можешь не заметить, как li зачеркнулся и раскеркнулся за мгновение - просто потому что это происходит очень быстро. Но технически это так

Если такое поведение мешает - можно отменять `click` при двойном клике через таймер, но это уже будет в разделе асинхронность

```javascript
// Создай кнопку "Генератор"

// При клике на div - число увеличивается на 1
// При клике на отдельную кнопку "Очистить" - все созданные div удаляются
```

```javascript
const container = document.querySelector("#container"); // находим контейнер
const buttonRand = document.querySelector("#generator"); // кнопку "Генератор"
const buttonClear = document.querySelector("#clear"); // кнопку "Очистить"

buttonRand.addEventListener("click", function() { // при клике на "Генератор"
    const newDiv = document.createElement("div"); // создаём div
    const newPar = document.createElement("p"); // создаём абзац

    newPar.textContent = Math.floor(Math.random() * 100) + 1; // случайное число от 1 до 100

    newPar.addEventListener("click", function() { // при клике на абзац
        newPar.textContent = Number(newPar.textContent) + 1; // увеличиваем число на 1
    });

    newDiv.append(newPar); // собираем карточку
    container.append(newDiv); // добавляем в контейнер
});

buttonClear.addEventListener("click", function() { // при клике на "Очистить"

});
```

> `Math.floor(Math.random() * 100) + 1` - генерирует случайное целое от 1 до 100. `Math.random()` даёт от 0 до 1 (не включая 1), умножаем на 100 - от 0 до 100, `Math.floor` округляет вниз до целого, `+ 1` сдвигает диапазон на 1. Без `+ 1` было бы от 0 до 99

> При клике на абзац `Number(newPar.textContent) + 1` - превращаем текст в число и увеличиваем. Без `Number()` получилась бы строка: `"5" + 1` → `"51"`, а не `6`

> Очистка через `container.textContent = ""` - удаляет всё содержимое контейнера разом. Проще, чем удалять каждый div по отдельности циклом.

> Кнопка «Очистить» вынесена наружу - она статичная, создана в HTML, поэтому обработчик висит один раз. Если бы она создавалась внутри «Генератора», обработчик навешивался бы заново при каждом клике.
