## Этап 1. Работа с атрибутами

Атрибуты - это характеристики HTML-элементов: `id`, `class`, `href`, `src`, `value`, `type`, `placeholder` и другие. Через JS можно читать и менять их

---

### element.id

`element.id` - свойство, которое хранит id элемента. Можно прочитать и изменить

```html
<div id="card">Карточка</div>
```

```javascript
const card = document.querySelector("div");

console.log(card.id); // "card" - читаем id
card.id = "newCard";  // меняем id на новый
console.log(card.id); // "newCard"
```

После изменения id на странице элемент остаётся тем же, но его id в HTML-атрибуте обновится. По старому `#card` его уже не найти

---

**Задачи**

```javascript
// 1. Найди элемент с id "card" и выведи его id в абзац
```

<details>
<summary>Ответ</summary>

```html
<div id="card">Карточка</div>
<p id="output"></p>
```

```javascript
const card = document.querySelector("#card");
const output = document.querySelector("#output");

output.textContent = card.id;
```

</details>

```javascript
// 2. Найди элемент с классом "item" и поменяй его id на "selected"
```

<details>
<summary>Ответ</summary>

```html
<div class="item">Элемент</div>
```

```javascript
const item = document.querySelector(".item");
item.id = "selected";
```

</details>

```javascript
// 3. Найди кнопку и выведи в абзац "У кнопки id: " + её id, если id есть. Если id пустой - выведи "У кнопки нет id"
```

<details>
<summary>Ответ</summary>

```html
<button id="submit">Отправить</button>
<p id="output"></p>
```

```javascript
const button = document.querySelector("button");
const output = document.querySelector("#output");

if (button.id === "") {
    output.textContent = "У кнопки нет id";
} else {
    output.textContent = "У кнопки id: " + button.id;
}
```

</details>

### element.className

**`element.className`** - свойство, которое хранит все классы элемента одной строкой. Можно прочитать и заменить целиком

```html
<div class="card active">Карточка</div>
```

```javascript
const card = document.querySelector("div");

console.log(card.className); // "card active" - читаем все классы
card.className = "newClass"; // заменяем все классы на один
console.log(card.className); // "newClass"
card.className = "card selected"; // или заменяем все классы на два
console.log(card.className); // "card selected"
```

`className` перезаписывает **все** классы разом. Если было `"card active"`, а ты присвоил `"newClass"` - оба старых класса исчезнут, останется только `newClass`

**Когда использовать `className`, а когда `classList`:**

`className` - грубый инструмент. Если нужно заменить **все** классы разом - он подходит

Но если нужно взять только один класс (например, второй), заменить один класс на другой или добавить/убрать конкретный класс - используй `classList`. Он работает с каждым классом отдельно:

```javascript
element.classList.add("active");          // добавить
element.classList.remove("active");       // убрать
element.classList.toggle("active");       // переключить
element.classList.contains("active");     // проверить наличие
```

`className` - для замены всей строки классов. `classList` - для точечной работы с отдельными классами

---

**Задачи**

```javascript
// 1. Найди элемент и выведи его className в абзац
```

```html
<div class="card active">Карточка</div>
<p id="output"></p>
```

<details>
<summary>Ответ</summary>

```javascript
const card = document.querySelector("div");
const output = document.querySelector("#output");

output.textContent = card.className;
```

</details>

```javascript
// 2. Замени все классы элемента на "highlight"
```

```html
<div class="card active">Карточка</div>
```

<details>
<summary>Ответ</summary>

```javascript
const card = document.querySelector("div");
card.className = "highlight";
```

</details>

```javascript
// 3. Найди кнопку. Если у неё в className есть "active" - убери класс через className, оставив только "btn"
// Используй indexOf
```

```html
<button class="btn active">Кнопка</button>
```

<details>
<summary>Ответ</summary>

```javascript
const button = document.querySelector("button");

if (button.className.indexOf("active") !== -1) {
    button.className = "btn";
}
```

> Почему мы использовали indexOf, а не contains?
> `contains` - это метод `classList`, а не строки. Работает с отдельными классами:

```javascript
element.classList.contains("active"); // true или false
```

А `className` - это **строка**. У строки нет `contains`, у неё есть `includes` и `indexOf`. Поэтому:

```javascript
element.className.includes("active"); // true или false
element.className.indexOf("active") !== -1; // то же самое
```

Но есть нюанс. `className.includes("active")` или `className.indexOf("active")` найдёт `"active"` и в `"inactive"`. Потому что это подстрока, а не отдельный класс. `classList.contains("active")` точнее - проверяет именно класс целиком. Поэтому для проверки классов лучше `classList.contains`, а не `className.includes`

</details>

### element.value

`element.value` - свойство полей ввода. Хранит то, что ввёл пользователь. Можно читать и менять

```html
<input type="text" id="name">
```

```javascript
const input = document.querySelector("#name");

console.log(input.value); // "" - пусто

console.log(input.value); // "Анна"
```

`value` работает у `<input>`, `<textarea>`, `<select>`. У обычных элементов (`<p>`, `<div>`) такого свойства нет

**Задачи**


<details>
<summary>Ответ</summary>

```javascript
const input = document.querySelector("#name");
const output = document.querySelector("#output");

output.textContent = input.value;
```

</details>

```javascript
// 2. Установи в поле значение "Привет" и выведи его в консоль
```

```html
<input type="text" id="name">
```

<details>
<summary>Ответ</summary>

```javascript
const input = document.querySelector("#name");
input.value = "Привет";
console.log(input.value);
```

</details>

```javascript
// 3. Дано поле. Выведи в абзац значение свойства value. При клике на кнопку - поменяй value на "новое" и выведи его снова. 
```

```html
<input type="text" id="name" value="старт">
<button id="change">Поменять</button>
<p id="output"></p>
```

<details>
<summary>Ответ</summary>

```javascript
const input = document.querySelector("#name");
const button = document.querySelector("#change");
const output = document.querySelector("#output");

output.textContent = input.value;

button.addEventListener("click", function() {
    input.value = "новое";
    output.textContent = input.value;
});
```

</details>

### element.href

`element.href` - свойство ссылки `<a>`. Хранит адрес, на который ведёт ссылка. Можно прочитать и изменить

Это значит: если в HTML написать короткий путь, браузер всё равно вернёт полный адрес

```html
<a id="link" href="/page">Ссылка</a>
```

```javascript
const link = document.querySelector("#link");
console.log(link.href);                  // "http://localhost:5500/page" - полный URL
console.log(link.getAttribute("href"));  // "/page" - как было в HTML
```

Про `getAttribute` будет написано ниже. Можешь вернуться сюда после его изучения для лучшего понимания

В HTML ты написал `/page` - короткий путь. Но `link.href` (свойство) вернёт **полный адрес**, добавив домен и протокол. Браузер сам достраивает путь до абсолютного

Если в HTML уже был полный адрес (`https://google.com`), то `link.href` вернёт его же, но с завершающим слешем: `https://google.com/`

**Сравнение:**

| В HTML | `link.href` (свойство) | `link.getAttribute("href")` |
|--------|------------------------|------------------------------|
| `/page` | `http://localhost:5500/page` | `/page` |
| `https://google.com` | `https://google.com/` | `https://google.com` |
| `page.html` | `http://localhost:5500/page.html` | `page.html` |

Вот почему для ссылок `getAttribute("href")` иногда точнее - он показывает ровно то, что написано. А `link.href` - всегда полный URL, удобный для переходов и проверок

---

**Задачи**

```javascript
// 1. Прочитай href ссылки и выведи в абзац
```

```html
<a id="link" href="https://google.com">Гугл</a>
<p id="output"></p>
```

<details>
<summary>Ответ</summary>

```javascript
const link = document.querySelector("#link");
const output = document.querySelector("#output");

output.textContent = link.href;
```

</details>

```javascript
// 2. Поменяй адрес ссылки на https://yandex.ru и текст на "Яндекс". Выведи ссылку в абзац
```

```html
<a id="link" href="https://google.com">Гугл</a>
<p id="output"></p>
```

<details>
<summary>Ответ</summary>

```javascript
const link = document.querySelector("#link");
const output = document.querySelector("#output");

link.href = "https://yandex.ru";
link.textContent = "Яндекс"
output.textContent = link.href
```

</details>

```javascript
// 3. Дана ссылка с коротким href="/page". Выведи в абзац значение свойства href. При клике на ссылку - если адрес начинается с "http://localhost", выведи "Локальная ссылка", иначе "Внешняя ссылка"
// Используй indexOf и preventDefault для отмены перехода по ссылке
```

```html
<a id="link" href="/page">Ссылка</a>
<p id="output"></p>
```

<details>
<summary>Ответ</summary>

```javascript
const link = document.querySelector("#link");
const output = document.querySelector("#output");

output.textContent = link.href;

link.addEventListener("click", function(event) {
    event.preventDefault();
    if (link.href.indexOf("http://localhost") === 0) {
        output.textContent = "Локальная ссылка";
    } else {
        output.textContent = "Внешняя ссылка";
    }
});
```

</details>


Браузер возвращает полный путь к файлу, даже если в HTML было короткое имя.

Вывод может быть такой: `http://127.0.0.1:5500/%D0%A1%D0%BE%D0%B1%D1%8B%D1%82%D0%B8%D1%8F/cat.jpg`

### element.disabled

`element.disabled` - свойство кнопок и полей. Если `true` - элемент отключён, с ним нельзя взаимодействовать. Если `false` - активен

```html
<button id="submit">Отправить</button>
```

```javascript
const button = document.querySelector("#submit");

button.disabled = true;  // отключили кнопку
button.disabled = false; // включили обратно
```

Отключённая кнопка выглядит серой и не реагирует на клики. Полезно, когда нужно заблокировать действие до выполнения условий.

---

**Задачи**

```javascript
// 1. Отключи кнопку при загрузке страницы
```

```html
<button id="submit">Отправить</button>
```

<details>
<summary>Ответ</summary>

```javascript
const button = document.querySelector("#submit");
button.disabled = true;
```

</details>

```javascript
// 2. При вводе текста в поле - если поле пустое, кнопка отключена, если непустое - активна
```

```html
<input type="text" id="name">
<button id="submit">Отправить</button>
```

<details>
<summary>Ответ</summary>

<details>
<summary>Ответ</summary>


### element.checked

`element.checked` - свойство чекбоксов и радиокнопок. `true` - отмечен, `false` - нет

```html
<input type="checkbox" id="agree">
```

```javascript
const checkbox = document.querySelector("#agree");

console.log(checkbox.checked); // false - не отмечен
checkbox.checked = true;       // отметили программно
```
Отметили программно - чекбокс станет отмеченным сразу после выполнения этой строки

Работает и для читаемости (проверить, отмечен ли), и для установки (отметить или снять)

---

**Задачи**

```javascript
// 1. Проверь, отмечен ли чекбокс, и выведи результат в абзац
// Используй событие change 
```

```html
<input type="checkbox" id="agree">
<p id="output"></p>
```

<details>
<summary>Ответ</summary>

```javascript
const checkbox = document.querySelector("#agree");
const output = document.querySelector("#output");

// вывод при загрузке
output.textContent = checkbox.checked;

// вывод при переключении
checkbox.addEventListener("change", function() {
    output.textContent = checkbox.checked; // для переключения 
});
```

Без `change` вывод был бы один раз - при загрузке страницы. Абзац показал бы `"false"` и всё. Клики по чекбоксу ничего бы не меняли, потому что нет обработчика, который следит за изменением

</details>

```javascript
// 2. Отметь чекбокс программно
```

```html
<input type="checkbox" id="agree">
```

<details>
<summary>Ответ</summary>

```javascript
const checkbox = document.querySelector("#agree");
checkbox.checked = true;
```

</details>

```javascript
// 3. При клике на кнопку - если чекбокс отмечен, включи кнопку "Отправить", иначе отключи
```

```html
<input type="checkbox" id="agree">
<button id="check">Проверить</button>
<button id="submit" disabled>Отправить</button>
```

<details>
<summary>Ответ</summary>

```javascript
const checkbox = document.querySelector("#agree");
const checkButton = document.querySelector("#check");
const submitButton = document.querySelector("#submit");

checkButton.addEventListener("click", function() {
    if (checkbox.checked) {
        submitButton.disabled = false;
    } else {
        submitButton.disabled = true;
    }
});
```

</details>

## Этап 2. Методы атрибутов

Четыре метода для работы с любыми атрибутами HTML. В отличие от свойств (`element.id`, `element.href`), эти методы работают с **любым** атрибутом: стандартным (`href`, `src`, `title`) и своим (`data-*`)

### getAttribute

`getAttribute("имя")` - читает значение любого атрибута элемента по его имени. Возвращает **строку** или `null`, если атрибута нет

```html
<a id="link" href="https://google.com" target="_blank" data-id="37">Гугл</a>
```

```javascript
const link = document.querySelector("#link");

console.log(link.getAttribute("href"));   // "https://google.com"
console.log(link.getAttribute("target")); // "_blank"
console.log(link.getAttribute("data-id")); // "37"
console.log(link.getAttribute("class"));   // null - класса нет
```

`getAttribute` возвращает то, что написано **в HTML**, а не текущее состояние. Для `value` поля ввода это значит: если пользователь что-то напечатал, `getAttribute("value")` всё равно вернёт исходное значение из HTML

**Отличие от свойств:**

Свойства (`link.href`, `input.value`) и методы атрибутов (`getAttribute`, `setAttribute`) часто дают похожий результат, но работают по-разному

**Пример 1.** Ссылка:

```html
<a id="link" href="/page">Ссылка</a>
```

```javascript
console.log(link.href);                  // "http://localhost:5500/page" - полный URL
console.log(link.getAttribute("href"));  // "/page" - как в HTML
```

Свойство `href` достраивает путь до полного. `getAttribute` возвращает ровно то, что написано

**Пример 2.** Поле ввода:

```html
<input type="text" id="name" value="старт">
```

```javascript
input.value = "новое";
console.log(input.value);                  // "новое" - свойство живое
console.log(input.getAttribute("value"));  // "старт" - атрибут не изменился
```

Свойство `value` меняется вместе с вводом пользователя. Атрибут `value` остаётся тем, что было в HTML при загрузке

**Пример 3.** Чекбокс:

```html
<input type="checkbox" id="agree" checked>
```

```javascript
agree.checked = false;
console.log(agree.checked);                 // false - свойство поменялось
console.log(agree.getAttribute("checked")); // "" - атрибут остался
```

В HTML стоит `checked` - при загрузке чекбокс отмечен. Свойство `checked` показывает текущее состояние: снял галочку - стало `false`. А атрибут остаётся в HTML и не меняется. `getAttribute("checked")` возвращает пустую строку, потому что атрибут есть, но без значения

> **Что значит `getAttribute("checked")` возвращает пустую строку, атрибут есть, но без значения?**
> 
> `checked` - это булев атрибут. У него нет значения. Он либо есть, либо его нет
>
> ```html
> <input type="checkbox" checked>   <!-- атрибут есть, чекбокс отмечен -->
> <input type="checkbox">           <!-- атрибута нет, чекбокс не отмечен -->
> ```
>
> Нельзя написать `checked="true"` или `checked="false"` - это не сработает так, как ты думаешь. Если атрибут есть - чекбокс отмечен, независимо от значения. Если атрибута нет - не отмечен
>
> Поэтому `getAttribute("checked")` возвращает `""` - атрибут есть, но значения у него нет. Пустая строка
>
> Такие же булевы атрибуты: `disabled`, `required`, `readonly`, `selected`, `hidden`. Все они работают по принципу «есть или нет», без значения
>
> **Зачем тогда `getAttribute`?**
>
> Для булевых атрибутов есть `hasAttribute` - возвращает `true` или `false`, точнее показывает наличие
>
> ```javascript
> input.hasAttribute("checked"); // true или false
> input.getAttribute("checked"); // "" или null
> ```
>
> Но живое состояние чекбокса смотрят через свойство `element.checked` - оно показывает текущее, а не начальное из HTML

- **Свойства** отражают **текущее состояние** элемента. Меняются, когда пользователь что-то делает
- **Атрибуты** - это **снимок из HTML** на момент загрузки. Остаются прежними, даже если состояние изменилось

---

**Задачи**

```javascript
// 1. Выведи в абзац значение атрибута alt у картинки
```

### setAttribute

`setAttribute("имя", "значение")` - устанавливает значение атрибута. Если атрибут есть - перезаписывает, старое значение затирается. Если нет - создаёт новый. Второй аргумент всегда должен быть **строкой**. Даже если пишешь число - будет `"24"`, не `24`. То же с `setAttribute("width", 200)` - станет `"200"`

```html
<a id="link" href="https://google.com" target="_blank" data-id="37">Гугл</a>
```

```javascript
const link = document.querySelector("#link");

link.setAttribute("href", "https://yandex.ru"); // поменяли адрес
link.setAttribute("title", "Поисковик");        // создали новый атрибут
link.setAttribute("data-id", "24");             // поменяли свой атрибут
```

Булевы атрибуты (`disabled`, `checked`) устанавливают с пустой строкой: `setAttribute("disabled", "")`. Нельзя написать `setAttribute("disabled", "true")` и ожидать того же

**Отличие от свойств:**

Свойства (`link.href`, `input.value`) и методы атрибутов (`getAttribute`, `setAttribute`) часто дают похожий результат, но работают по-разному

**Пример 1.** Ссылка:

```html
<a id="link" href="https://google.com">Гугл</a>
```

```javascript
link.setAttribute("href", "https://yandex.ru"); // атрибут в HTML обновится
link.href = "https://yandex.ru";                // свойство тоже обновит ссылку
```

Здесь результат один и тот же - ссылка ведёт на Яндекс. Разница только в том, что `setAttribute` пишет в HTML, а `href` управляет свойством

**Пример 2.** Поле ввода:

```html
<input type="text" id="name" value="старт">
```

```javascript

// пользователь стёр "старт" и ввёл "привет"
input.value = "привет";

console.log(input.value);                  // "привет" - свойство живое
console.log(input.getAttribute("value"));  // "старт" - атрибут не изменился
```

Свойство `value` напрямую управляет тем, что в поле. Атрибут `value` - это значение по умолчанию, и после того как пользователь начал вводить, оно перестаёт влиять на видимое содержимое

**Пример 3.** Чекбокс:

```html
<input type="checkbox" id="agree">
```

```javascript
agree.checked = true;                       // свойство - галочка появится
agree.setAttribute("checked", "");          // атрибут - тоже поставит галочку
```

Для `checked` оба способа работают, потому что браузер синхронизирует их. Но если потом написать `agree.checked = false` - галочка снимется, а атрибут `checked` в HTML останется. Они расходятся

**Когда использовать `setAttribute`:**

- Когда у атрибута нет свойства. Например, `data-id`, `aria-label`, нестандартные атрибуты
- Когда нужно изменить именно HTML-атрибут, а не состояние
- Для обычных атрибутов (`href`, `src`, `title`, `placeholder`) - что удобнее, то и используй. Результат одинаковый

### hasAttribute

`hasAttribute("имя")` - проверяет, есть ли у элемента указанный атрибут. Возвращает `true` или `false`. Проверяет **наличие**, а не значение, даже если атрибут пустой - вернёт `true`

```html
<a id="link" href="https://google.com" target="_blank">Гугл</a>
```

```javascript
const link = document.querySelector("#link");

console.log(link.hasAttribute("href"));    // true - атрибут есть
console.log(link.hasAttribute("target"));  // true
console.log(link.hasAttribute("title"));   // false - атрибута нет
console.log(link.hasAttribute("class"));   // false
```

**Отличие от getAttribute:**

`getAttribute("checked")` возвращает `""` или `null`, а `hasAttribute("checked")` - `true` или `false`. Для булевых атрибутов `hasAttribute` удобнее

```html
<input type="checkbox" id="agree" checked>
```

```javascript
console.log(agree.getAttribute("checked")); // "" - пустая строка, не поймёшь сразу
console.log(agree.hasAttribute("checked")); // true - понятнее
```

Тут разница важная. `getAttribute` для булевого атрибута вернёт пустую строку, и надо помнить, что `""` означает «атрибут есть». А `hasAttribute` сразу даёт `true` или `false` - читается легко

---

**Пример 1.** Ссылка

```html
<a id="link" href="https://google.com">Гугл</a>
```

```javascript
link.hasAttribute("href");   // true - атрибут есть
link.hasAttribute("target"); // false - атрибута нет
```

Проверяем наличие атрибутов. `href` установлен - вернёт `true`. `target` нет - вернёт `false`

**Пример 2.** Поле ввода

```html
<input type="text" id="name" placeholder="Введите имя">
```

```javascript
input.hasAttribute("placeholder"); // true - подсказка установлена
input.hasAttribute("value");       // false - атрибута value нет
```

Проверяем, что установлено. `placeholder` есть - `true`. `value` не задан в HTML - `false`

Тут разница с `getAttribute`: если бы у поля был атрибут `value=""`, `getAttribute("value")` вернул бы пустую строку, а `hasAttribute("value")` - `true`. Потому что атрибут есть, просто пустой. `hasAttribute` смотрит на наличие, а не на значение

**Пример 3.** Чекбокс

```html
<input type="checkbox" id="agree" checked>
```

```javascript
agree.hasAttribute("checked"); // true - атрибут стоит
agree.checked = false;         // снимаем галочку через свойство
agree.hasAttribute("checked"); // true - атрибут остался!
```

Вот тут важное. `hasAttribute` смотрит на **HTML**, а не на текущее состояние. Снял галочку через `checked = false` - свойство изменилось, а атрибут `checked` в HTML остался. `hasAttribute` продолжит возвращать `true`

С `getAttribute`:

```javascript
agree.getAttribute("checked"); // "" - пустая строка, потому что булев атрибут
```

`hasAttribute` удобнее: сразу `true` или `false`, без пустых строк

**Пример 4.** Кнопка

```html
<button id="btn" disabled>Отправить</button>
```

```javascript
button.hasAttribute("disabled"); // true - кнопка отключена
button.disabled = false;         // включаем кнопку через свойство
button.hasAttribute("disabled"); // true - атрибут остался
```

Свойство сильнее атрибута. Кнопка работает, потому что `disabled = false`, хотя атрибут в HTML остался. Если бы мы хотели убрать и атрибут, то использовали бы `removeAttribute("disabled")`. Но для работы кнопки достаточно свойства

**Когда использовать:**

- Проверить, стоит ли у элемента атрибут. Особенно для булевых (`disabled`, `checked`, `hidden`)
- Условие перед `setAttribute` или `removeAttribute`: если атрибута нет - создать, если есть - удалить
- Проверка данных: `hasAttribute("data-id")` - есть ли у элемента id товара

### removeAttribute

`removeAttribute("имя")` - удаляет атрибут у элемента. Если атрибута нет - ничего не произойдёт и ошибки не будет. Для булевых атрибутов (`disabled`, `checked`) - убирает флаг. Кнопка станет активной, чекбокс - неотмеченным

```html
<a id="link" href="https://google.com" target="_blank" title="Поисковик">Гугл</a>
```

```javascript
const link = document.querySelector("#link");

link.removeAttribute("target"); // убрали target
link.removeAttribute("title");  // убрали title
```

Стало: `<a id="link" href="https://google.com">Гугл</a>`

**Нюанс с булевыми атрибутами**

`removeAttribute` убирает атрибут из HTML. Но для булевых атрибутов (`disabled`, `checked`) у элемента есть ещё и **свойство** с тем же именем. Атрибут и свойство - это два разных слоя. Браузер синхронизирует их при загрузке, но после изменений через JS они могут разойтись.

```html
<button id="btn" disabled>Отправить</button>
```

```javascript
const button = document.querySelector("#btn");

button.removeAttribute("disabled");
console.log(button.hasAttribute("disabled")); // false - атрибута нет
console.log(button.disabled);                 // false - свойство тоже сброшено
```

В этом случае всё сработало - кнопка активна. По спецификации `removeAttribute("disabled")` синхронизирует и свойство в `false`. Но если до этого ты менял свойство через JS, они могут разойтись. Поэтому для надёжности сбрасывают оба:

```javascript
button.removeAttribute("disabled");
button.disabled = false;
```

Так кнопка точно станет активной, независимо от того, что было раньше.

## Этап 3. data-атрибуты

`data-*` - специальные атрибуты для хранения своих данных на элементе которые всегда начинается с `data-`. Браузер их не использует, они только для тебя

```html
<div class="card" data-id="37" data-color="red">Карточка</div>
```

Доступ через `dataset`:

```javascript
const card = document.querySelector(".card");

console.log(card.dataset.id);    // "37"
console.log(card.dataset.color); // "red"
```

Через `dataset` имя пишется в camelCase: `data-user-name` → `dataset.userName`. Можно и читать, и менять, и добавлять:

```javascript
card.dataset.size = "large"; // создали data-size="large"
card.dataset.color = "blue"; // поменяли
delete card.dataset.color;   // удалили
```

**data-id** - id записи в базе данных. Чтобы связать элемент на странице с записью на сервере. Есть в списке задач, товаров, пользователей. В отличие от простых id, data-id может повторяться сколько угодно раз даже с одинаковыми названиями. Хоть два одинаковых технически допускается, но логически это бессмысленно, потому что если два элемента ссылаются на один data-id, значит, они ссылаются на одну и ту же запись в базе. Для задач, товаров, пользователей это неправильно - каждая запись должна быть уникальной

**data-priority** - приоритет задачи: `"high"`, `"low"`. По нему можно фильтровать, сортировать или подсвечивать. "high" и "low" - это просто пример значений, которые ты сам придумываешь

**data-category** - категория товара: `"электроника"`, `"одежда"`. Фильтр по категориям

**data-price** - цена товара. Для подсчёта суммы в корзине

**data-date** - дата создания или дедлайн. Для сортировки по дате

**data-status** - статус задачи: `"active"`, `"done"`, `"archived"`. Меняется при переключении. Тут тоже названия как примеры, можешь называть как хочешь

Это только примеры, но не стандарт. Можно писать `data-что-угодно`, главное чтобы имя было валидным, то есть, чтобы были строчные буквы, не начиналось с цифры и был дефис между словами. Если использовать заглавные буквы в HTML, то в JS они превращаются в camelCase

**Пример:**

```html
<div data-uSeR-nAMe="Анна" data-NomER="37"></div>
```

```javascript
const div = document.querySelector("div");

console.log(div.dataset.userName); // "Анна"
console.log(div.dataset.nomer);    // "37"
```

То есть в JS мы всё равно обращаемся к `data-*` в camelCase, даже если некоторые буквы заглавные

**Пример со списком задач**

```html
<ul id="list">
    <li data-id="1">Купить хлеб</li>
    <li data-id="2">Помыть посуду</li>
    <li data-id="3">Позвонить маме</li>
</ul>
```

У каждой задачи есть `data-id` - её номер. Он ни на что не влияет. Для браузера это просто текст в HTML

Зато твой JS может его прочитать:

```javascript
const items = document.querySelectorAll("li");

for (let item of items) {
    console.log(item.dataset.id); // "1", "2", "3"
}
```

Теперь представь, что задачи хранятся где-то на сервере, и при клике на «Удалить» нужно удалить именно ту, по которой кликнули. Как понять, какую удалять? По `data-id`:

```javascript
list.addEventListener("click", function(event) {
    if (event.target.tagName === "LI") {
        const id = event.target.dataset.id;
        console.log("Удалить задачу с id: " + id);
        event.target.remove();
    }
});
```

Кликнул по «Помыть посуду» - `dataset.id` вернёт `"2"`. Ты знаешь, какую задачу удалять

> **Зачем это, если можно просто удалить `li`?**
>
> для удаления `li` со страницы `data-id` не нужен. Разница появляется, когда данные хранятся на сервере
> Пример: у тебя есть список задач в базе данных и у каждой записи есть id: 1, 2, 3. На странице ты создаёшь `li` для каждой задачи и записываешь в `data-id` совпадающий id из базы. Кликнул по «Удалить» - берёшь `data-id="2"` и отправляешь на сервер: «удали запись с id 2». Сервер удаляет из базы. И только потом ты удаляешь `li` со страницы
> Получается, чтобы удалить с базы и со страницы нужно использовать и event.target для удаления со страницы, и data для удаления с сервера. С базой данных будем работать в асинхронности

data-* нужны и без сервера - чтобы хранить данные на элементе и использовать их в фильтрации, сортировке, поиске. А когда появится сервер, можно будет сохранять данные между сессиями и связывать элементы страницы с записями в базе данных

## Этап 4. Атрибуты vs свойства

У одного и того же элемента есть **атрибуты** (то, что в HTML) и **свойства** (то, что в JS). Они часто совпадают, но не всегда.

| Атрибут (HTML) | Свойство (JS) | Работает так же? |
|----------------|---------------|-------------------|
| `id="card"` | `element.id` | Да |
| `href="..."` | `element.href` | Да, но JS возвращает полный URL |
| `class="a b"` | `element.className` | Да, но есть ещё `classList` |
| `value="5"` | `element.value` | Нет - свойство живое, меняется при вводе |
| `checked` | `element.checked` | Нет - атрибут начальное, свойство текущее |
| `data-id="22"` | `element.dataset.id` | Да, `но dataset.id` вернёт строку|

**Ключевая разница:**

Атрибут - это то, что было в HTML при загрузке. Свойство - текущее состояние в JS

Пример с чекбоксом:

```html
<input type="checkbox" id="agree" checked>
```

```javascript
const cb = document.querySelector("#agree");

console.log(cb.checked);                    // true - свойство
console.log(cb.getAttribute("checked"));    // "" - атрибут (просто есть)

cb.checked = false;
console.log(cb.checked);                    // false - свойство
console.log(cb.getAttribute("checked"));    // "" - атрибут не изменился
```

Свойство `checked` меняется, а атрибут `checked` остаётся. Поэтому не всегда можно заменить одно другим

**Когда что использовать:**

- **Свойство** (`element.value`, `element.checked`) - для живых данных, которые меняются. Быстрее и удобнее
- **Методы атрибутов** (`getAttribute`, `setAttribute`) - для атрибутов, у которых нет свойства, или для нестандартных атрибутов
- **`data-*`** - для своих данных, не влезающих в стандартные атрибуты

## Кратко по всем методам

- `element.id` - id элемента (`""`, если нет)
- `element.className` - все классы строкой (`""`, если нет)
- `element.value` - значение поля ввода (`""`, если пусто)
- `element.href` - адрес ссылки (`""`, если нет)
- `element.src` - путь картинки (`""`, если нет)
- `element.disabled` - отключён ли элемент (`true`/`false`)
- `element.checked` - отмечен ли чекбокс (`true`/`false`)
- `getAttribute("name")` - прочитать атрибут (`null`, если нет)
- `setAttribute("name", "value")` - установить атрибут (ничего не возвращает)
- `("name")` - проверить наличие (`true`/`false`)
- `removeAttribute("name")` - удалить атрибут (ничего не возвращает)
- `element.dataset.key` - прочитать data-атрибут (`undefined`, если нет)
- `element.dataset.key = "value"` - установить data-атрибут
- `delete element.dataset.key` - удалить data-атрибут
