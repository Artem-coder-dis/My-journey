## События

### Этап 1. Основные события мыши и клавиатуры

События позволяют реагировать на действия пользователя: клики, ввод текста, отправку формы, нажатия клавиш

`addEventListener` - повесить обработчик события

```javascript
element.addEventListener("типСобытия", функцияКотораяСработает);
```

**click** - клик по элементу

```html
<button id="submit">Отправить</button>
```

```javascript
const button = document.querySelector("#submit");
button.addEventListener("click", function() {
    console.log("Кнопка нажата!");
});
```

При каждом клике по кнопке в консоль выводится сообщение "Кнопка нажата!". Функция-обработчик выполняется в момент события

**dblclick** - двойной клик

```html
<button id="submit">Отправить</button>
```

```javascript
const button = document.querySelector("#submit");
button.addEventListener("dblclick", function() {
    console.log("Двойной клик!");
});
```

Срабатывает при двойном клике по элементу

**keydown** - нажатие клавиши

```html
<input type="text" id="name" placeholder="Введите имя">
```

```javascript
const input = document.querySelector("#name");
input.addEventListener("keydown", function(event) {
    console.log(event.key); // какая клавиша нажата
});
```

`function(event)` - это функция-обработчик, которую вызывает браузер, когда происходит событие. А `event` - это просто имя параметра, оно может быть любое

В `click` тебе может быть без разницы, куда именно кликнули, какая кнопка мыши - просто сработало и всё. А в `keydown` тебе обязательно нужно знать, какая клавиша нажата

`event` нужен только когда ты используешь данные о событии. Если не используешь - можно не писать. Браузер всё равно передаст объект, но если параметр не объявлен, ты просто не получишь к нему доступ

> Что тогда такое .key?

`event.key` - это строка, в которой браузер сообщает, какая клавиша была нажата. Не код клавиши, а её название

```javascript
event.key
// "Enter" - клавиша Enter
// "a" - буква a
// "Escape" - клавиша Esc
// "ArrowUp" - стрелка вверх
// " " - пробел
```

`key` - это свойство объекта `event` к которому ты обращаешься через точку: `event.key`. Внутри - строка с названием клавиши, которую можно сравнивать с нужной: `if (event.key === "Enter")`

> О каком объекте идёт речь? 

Если вывести в консоль

```javascript
document.addEventListener("keydown", function(event) {
    console.log(event);
});
```

Визуально он будет выглядеть так:

```javascript
{
    key: "a",              // название клавиши
    code: "KeyA",          // физическое расположение клавиши
    altKey: false,         // зажат ли Alt
    ctrlKey: false,        // зажат ли Ctrl
    shiftKey: false,       // зажат ли Shift
    metaKey: false,        // зажат ли Cmd (на Mac)
    repeat: false,         // зажата ли клавиша
    isComposing: false,    // идёт ли ввод через IME (редко)
    location: 0,           // расположение клавиши (левая/правая)
    type: "keydown",       // тип события
    target: <input>,       // элемент, на котором произошло событие
    timeStamp: 123456789,  // количество миллисекунд, прошедших с момента загрузки страницы
}
```

Это не все свойства, но те, что реально используются

**repeat**

Если зажать клавишу и не отпускать, браузер начинает повторять событие keydown снова и снова. Свойство repeat показывает, произошло ли это повторное срабатывание. Первое нажатие - `repeat: false`, все последующие (пока клавиша зажата) - `repeat: true`

**isComposing**

это система ввода для языков с иероглифами, например китайского, японского, корейского. Пользователь печатает латиницей, а система предлагает варианты иероглифов, и он выбирает нужный

Человек, который пишет по-китайски, не может просто нажать клавишу "иероглиф" - на клавиатуре их нет. Вместо этого он печатает латинскими буквами, как читается слово. Например, печатает nihao

Компьютер видит это и показывает список иероглифов, которые звучат как "nihao". Например:

```text
你好 - привет
你 - ты
尼 - монах
```

Пользователь выбирает нужный вариант, и только тогда в поле ввода появляется иероглиф. Пока он выбирает, ввод находится в «режиме составления» - `isComposing: true`. Когда выбрал - `false`

keydown срабатывает на каждую латинскую букву, хотя пользователь ещё не выбрал иероглиф. Ты начнёшь отправлять запросы на `n`, `ni`, `nih`, `niha`, `nihao` - а это лишние запросы

Это как подсказки T9 на старых телефонах: нажимаешь кнопки с цифрами, а телефон предлагает слова

Для русскоязычных и англоязычных приложений это почти не встречается. Но если твой сайт будет работать на международном рынке - важно. Пока просто знай, что такое есть

**location**

`location` показывает, какая из одинаковых клавиш нажата:

- `0` - стандартная (обычные клавиши)
- `1` - левая (левый Shift, левый Ctrl, левый Alt)
- `2` - правая (правый Shift, правый Ctrl, правый Alt)
- `3` - цифровая клавиатура (NumPad)

Для обычной клавиши "a" будет `0`, для левого Shift - `1`, для правого Shift - `2`

Было у меня задание. При клике на кнопку заменить текст абзаца с id output на "Привет, " + значение из поля ввода. И я написал: 

```html
<button id="btn">Нажми</button>
<input type="text" id="name" placeholder="Введите имя">
<p id="output"></p>
```

```javascript
const click = document.querySelector("#btn");
const output = document.querySelector("#output");
const name = document.querySelector("#name");

click.addEventListener("click", function() {
    output.textContent = "Привет, " + name.textContent;
});
```

Но была одна небольшая ошибка:

`name.textContent` - у поля ввода текст лежит в `value`, а не в `textContent`, правильно:

```javascript
output.textContent = "Привет, " + name.value;
```

`value` - это свойство полей ввода, которое хранит то, что пользователь ввёл. Он есть у элементов форм: `<input>`, `<textarea>`, `<select>`. Для них текст хранится в `value`, а не в `textContent`. Это просто свойство элемента, как `textContent`, только для форм. Браузер сам обновляет его, когда пользователь печатает

Ещё была одна итересная задача. При клике на кнопку менять цвет фона страницы на случайный

```html
<button id="rand">Рандомный цвет</button>
```

```javascript
const rand = document.querySelector("#rand");

rand.addEventListener("click", function() {
    const r = Math.floor(Math.random() * 255);
    const g = Math.floor(Math.random() * 255);
    const b = Math.floor(Math.random() * 255);
    document.body.style.backgroundColor = `rgb(${r}, ${g}, ${b})`;
});
```

`rgb(...)` - формат цвета. Внутри три числа: красный, зелёный, синий. `Math.random() * 255` - генерирует случайное число от 0 до 255. Три таких вызова дают три случайных числа

`Math.random()` изначально даёт от 0 до 1 (не включая 1). `* 255` - от 0 до 255 (не включая 255)

Выпасть может любое число, например, 0.55. Мы умножаем его на 255 = 140.25 и округление в браузере обычно происходит **вниз**, но это в зависимости от браузера

Можно и в одну строку, но так читается тяжелее:

```javascript
document.body.style.backgroundColor = `rgb(${Math.floor(Math.random() * 255)}, ${Math.floor(Math.random() * 255)}, ${Math.floor(Math.random() * 255)})`;
```

> зачем Math.floor если браузер сам округляет число?

`Math.floor` нужен, если хочешь контролировать округление сам. Браузер округляет дробное значение, но его поведение может быть непредсказуемым - где-то вверх, где-то вниз

Если тебе нужны именно целые числа в нужном диапазоне, `Math.floor` даёт полный контроль: ты точно знаешь, что округлится вниз до целого от 0 до 254

Для случайного цвета разница не критична - можно и без `Math.floor`, браузер сам разберётся. Но для точных значений (например, индекс массива) округление важно, и там `Math.floor` обязателен

Можно умножать и на 256, чтобы затрагивало диапазон 255, но разница между 254 и 255 в цвете практически незаметна. Для случайного цвета это неважно

```javascript
// 4. ⭐ На странице кнопка и абзац с числом 0
// При клике на кнопку число увеличивается на 1
// Если число достигает 10 - кнопка исчезает (display: none)
// При двойном клике по абзацу число сбрасывается на 0
```

<details>
<summary>Ответ</summary>

```html

```

```javascript
const button = document.querySelector("#plusOne");
const counter = document.querySelector("#counter");
let count = 0;

button.addEventListener("click", function() {
    if (count < 9) {
        count += 1;
        counter.textContent = count;
    } else if (count === 9) {
        count += 1;
        counter.textContent = count;
        button.style.display = "none";
    }
});

counter.addEventListener("dblclick", function() {
    count = 0;  // счётчик тоже сбрасываем, иначе при нажатии на кнопку счёт продолжится с того места где остановился
    counter.textContent = 0;
    button.style.display = "";
});
```

### Этап 2. Дополнительные события: формы и фокус

**input** - ввод текста в поле

```html
<input type="text" id="name" placeholder="Введите имя">
```

```javascript
const input = document.querySelector("#name");
input.addEventListener("input", function() {
    console.log(input.value);
});
```

Срабатывает при каждом изменении текста в поле ввода. `input.value` - то, что ввёл пользователь

**submit** - отправка формы

```html
<form id="myForm">
    <input type="text" id="formName" placeholder="Введите имя">
    <button type="submit">Отправить</button>
</form>
```

```javascript
const form = document.querySelector("#myForm");
const input = document.querySelector("#formName");

form.addEventListener("submit", function(event) {
    event.preventDefault();
    console.log("Форма отправлена! Имя: " + input.value);
});
```

`event.preventDefault()` отменяет стандартное поведение браузера (перезагрузку страницы). Без него страница обновится, и ты не увидишь результат

**focus** - поле получило фокус (курсор внутри поля)

```html
<input type="text" id="name" placeholder="Введите имя">
```

```javascript
const input = document.querySelector("#name");
input.addEventListener("focus", function() {
    console.log("Поле в фокусе");
});
```

Срабатывает, когда пользователь кликает по полю или переходит на него клавишей Tab

**blur** - поле потеряло фокус (курсор ушёл из поля)

```html
<input type="text" id="name" placeholder="Введите имя">
```

```javascript
const input = document.querySelector("#name");
input.addEventListener("blur", function() {
    console.log("Поле потеряло фокус");
});
```

Срабатывает, когда пользователь кликает в другое место или переходит на другое поле

**change** - значение поля изменилось и поле потеряло фокус

```html
<input type="text" id="name" placeholder="Введите имя">
```

```javascript
const input = document.querySelector("#name");
input.addEventListener("change", function() {
    console.log("Новое значение: " + input.value);
});
```

В отличие от `input`, который срабатывает на каждый символ, `change` срабатывает один раз - когда пользователь закончил ввод и ушёл с поля. Удобно для проверки финального значения

**Задача.** Нужно написать код для проверки пароля. Поле ввода и абзац для сообщения. Пользователь вводит пароль, абзац обновляется в реальном времени:
- меньше 6 символов - "Слабый пароль" (красный текст)
- 6-9 символов - "Средний пароль" (оранжевый текст)
- 10 и больше - "Сильный пароль" (зелёный текст)

```html
<input type="text" id="password" placeholder="Введите пароль">
<p id="message"></p>
```

```javascript
const passwordInput = document.querySelector("#password");
const message = document.querySelector("#message");

passwordInput.addEventListener("input", function() {
    if (passwordInput.value.length < 6) {
        message.textContent = "Слабый пароль";
        message.style.color = "red";
    } else if (passwordInput.value.length <= 9) {
        message.textContent = "Средний пароль";
        message.style.color = "orange";
    } else {
        message.textContent = "Сильный пароль";
        message.style.color = "green";
    }
});
```

**Разбор:**

- `document.querySelector("#password")` - находим поле ввода по id
- `document.querySelector("#message")` - находим абзац для сообщения
- `passwordInput.addEventListener("input", ...)` - вешаем обработчик на событие `input`, которое срабатывает при каждом изменении текста в поле
- `passwordInput.value.length` - длина введённого пароля
- Если длина меньше 6 - выводим "Слабый пароль" и красим текст в красный
- Иначе если длина от 6 до 9 - выводим "Средний пароль" и красим в оранжевый
- Иначе (10 и больше) - выводим "Сильный пароль" и красим в зелёный
- Проверка идёт в реальном времени: каждый введённый символ обновляет сообщение и цвет

Это учебная задача. В реальных проектах проверяют наличие цифр, букв в разных регистрах, специальные символы и многое другое
