## textContent vs innerHTML

Оба свойства меняют содержимое элемента, но работают по-разному

**`textContent` - работает только с текстом**

Вставляет текст как есть. HTML-теги внутри станут обычным текстом, не сработают

```javascript
const el = document.querySelector("h1");
el.textContent = "<strong>Привет</strong>";
// На странице: <strong>Привет</strong> (тег отобразился как текст, не сработал)
```

**`innerHTML` - работает с HTML-разметкой**

Вставляет строку как HTML. Теги сработают, элементы создадутся

```javascript
const el = document.querySelector("h1");
el.innerHTML = "<strong>Привет</strong>";
// На странице: Привет (жирным шрифтом, тег strong сработал)
```

**Когда что использовать:**

- `textContent` - для обычного текста. Быстрее и безопаснее
- `innerHTML` - когда нужно вставить HTML-разметку (добавить теги, структуру). Осторожно с пользовательским вводом - можно получить XSS-уязвимость

&nbsp;

XSS (Cross-Site Scripting) - это уязвимость, когда злоумышленник вставляет свой JavaScript-код на твой сайт через поля ввода, комментарии, формы

Если ты берёшь пользовательский ввод и вставляешь его через `innerHTML`, скрипт внутри выполнится:

```javascript
// Пользователь ввёл: <script>alert("Ваши данные украдены!")</script>
el.innerHTML = userInput; // Скрипт выполнится!
```

Через `textContent` скрипт не выполнится - теги станут просто текстом. Поэтому для пользовательского ввода всегда `textContent`, а `innerHTML` - только если доверяешь источнику

> Почему первая буква X, а первое слово Cross?
>
> XSS расшифровывается как **Cross-Site Scripting**. Буква X вместо C - это сокращение от слова "Cross" (по-английски «кросс» звучит как «крест», что похоже на букву X). Так сложилось исторически, чтобы не путать с CSS (Cascading Style Sheets). Поэтому XSS, а не CSS

&nbsp;

**Пример с пользовательским вводом (как не надо):**

```javascript
// Пользователь ввёл <script>alert('XSS')</script>
el.innerHTML = userInput; // Опасно! Скрипт выполнится
el.textContent = userInput; // Безопасно - теги станут текстом
```

Для обычного текста всегда `textContent`. Для вставки HTML - `innerHTML`, но только если ты контролируешь источник

Контролировать источник - значит быть уверенным, что данные безопасны. `innerHTML` - только для HTML, который ты написал сам и которому доверяешь. `textContent` - для данных которые будут приходить от пользователя (сообщение в форме обратной связи, поле ввода имени пользователя и тд). **Задача.** Изменить заголовок h1 так, чтобы он стал курсивом через `innerHTML` (добавь тег `<em>`)

```html
<h1>Мой сайт</h1>
```

Для тех, кто хочет сначала попробовать решить сам, - я спрятал ответ

<details>
<summary>Ответ</summary>

Сначала я написал так:

```javascript
const el = document.querySelector("h1");
const edit = el.innerHTML = "<em>Мой сайт</em>";
console.log(edit);
```

Но можно было без вывода в консоль и без переменной `edit` - она просто хранит ту же строку, а это лишний шаг:

```javascript
const el = document.querySelector("h1");
el.innerHTML = "<em>Мой сайт</em>";
```

> **А если написать `console.log(edit.textContent)`, почему `undefined`?**
>
> Потому что `edit` - это строка `"<em>Мой сайт</em>"`, а не DOM-элемент. У строки нет свойства `textContent`, поэтому `undefined`

> **Как тогда строка добавляет HTML-элементы?**
>
> Строка сама не добавляет элементы. Это делает свойство `innerHTML`. Когда пишешь `el.innerHTML = "<em>Текст</em>"`, браузер читает строку, видит в ней HTML-теги и создаёт из них реальные DOM-элементы внутри `el`


> **А если бы я например написал el.innerHTML = "<fd>Текст</fd>"?**
> 
> Тег `<fd>` не существует в HTML. Браузер не распознает его и поведёт себя по-разному:
>
> - Текст `"Текст"` отобразится на странице
> - Сам тег `<fd>` будет проигнорирован (не добавит стилей), но может остаться в DOM как неизвестный элемент

Внешне страница не сломается, но и смысла в этом нет. Браузер просто не знает, что делать с несуществующим тегом, и обрабатывает его как обычный текст без форматирования

</details>

Задача. Нужно найти второй абзац с классом info и заменить его текст на "Новый важный абзац" так, чтобы слово "важный" стало жирным и подчёркнутым (использовать теги `<strong>` и `<u>`)

```html
<p class="info">Первый абзац</p>
<p class="info">Второй абзац</p>
<p class="info">Третий абзац</p>
```

<details>
<summary>Ответ</summary>

```javascript
const secondPar = document.querySelectorAll(".info");
secondPar[1].innerHTML = "Новый <strong><u>важный</u></strong> абзац"
```

`document.querySelectorAll(".info")` - находим все элементы с классом info. Это коллекция из трёх абзацев

`[1]` - берём второй элемент (индекс 1)

`innerHTML` - меняем содержимое элемента на HTML-строку
</details>
