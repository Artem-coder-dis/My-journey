## let vs const vs var

Один из самых частых вопросов на собеседовании: «чем отличаются let, const и var»

Коротко:
- `let` - переменная, которую можно изменить
- `const` - переменная, которую нельзя переприсвоить
- `var` - устаревший способ объявления переменной, который не стоит использовать

Теперь подробнее и с примерами

**let - можно изменить**

```javascript
let age = 25;
age = 26;
console.log(age); // 26 - поменяли, всё ок
```

**const - нельзя переприсвоить**

```javascript
const name = "Анна";
name = "Борис"; // Ошибка! TypeError: Assignment to constant variable
```

Но! Если `const` хранит объект или массив (подробнее в разделах Объекты и Массивы соответственно), их содержимое менять можно:

```javascript
const user = { name: "Анна" };
user.name = "Борис";
console.log(user.name); // "Борис" - свойство объекта изменили, ошибки нет

const arr = [1, 2, 3];
arr.push(4);
console.log(arr); // [1, 2, 3, 4] - массив изменили, ошибки нет
```

Нельзя переприсвоить саму переменную, но можно менять то, что внутри. `const` защищает ссылку, а не содержимое

**var - устаревший, не используй**

```javascript
var x = 1;
var x = 2; // можно объявить повторно (let и const такого не позволяют)
console.log(x); // 2
```

Главные проблемы `var`:
- Можно объявить одну и ту же переменную дважды - `let` и `const` запрещают это
- Игнорирует блочную область видимости `{}` - переменная видна за пределами блока (подробнее в посте про область видимости)
- Всплывает (hoisting) с `undefined`, что приводит к неожиданным багам (подробнее в посте про TDZ - временную мёртвую зону)
- Создаёт свойство на глобальном объекте `window`, а `let`/`const` - нет
  
> **Глобальный объект window - что это и почему var туда попадает**
> 
> В браузере есть глобальный объект `window`. Это самый верхний объект, в котором хранятся все глобальные переменные и функции. Увидеть его можно так: открой консоль (F12 → Console) и напиши `console.log(window)`. Разверни - увидишь сотни встроенных свойств и методов браузера
> 
> Когда ты объявляешь переменную через `var` в глобальной области, она становится свойством объекта `window`:
> 
> ```javascript
> var name = "Анна";
> console.log(window.name); // "Анна"
> ```
> 
> `let` и `const` так не делают:
> 
> ```javascript
> let age = 25;
> const city = "Москва";
> console.log(window.age);  // undefined
> console.log(window.city); // undefined
> ```
> 
> Чем это опасно: можно случайно перезаписать встроенное свойство браузера. Например, `var name = "Анна"` перезапишет `window.name` - свойство, которое браузер использует для имени окна. Или `var top = 5` сломает `window.top` - ссылку на родительское окно. Баги будут странные и трудные для отладки
> 
> `let` и `const` избавлены от этой проблемы - они не попадают в `window`, поэтому случайно ничего не сломаешь

Пример проблемы с `var`:

```javascript
if (true) {
    var test = "видно снаружи";
}
console.log(test); // "видно снаружи" - переменная утекла из блока
```

С `let` такого бы не было:

```javascript
if (true) {
    let test = "видно только внутри";
}
console.log(test); // Ошибка! ReferenceError: test is not defined
```

Почему `var` «утекает» из блока, а `let` нет - разбирается в посте про область видимости

**Задача 1.** Что выведет код? Объясни почему

```javascript
let a = 1;
const b = 2;
var c = 3;

if (true) {
    let a = 10;
    const b = 20;
    var c = 30;
    console.log(a, b, c); // ?
}

console.log(a, b, c); // ?
```

Разбор:
Внутри блока `if` создаются новые `let a` и `const b` - они живут только в этом блоке (подробнее в посте про область видимости). `var c = 30` перезаписывает глобальную переменную `c`, потому что `var` игнорирует блочную область видимости

Внутри блока: `10 20 30` (блочные a и b + перезаписанный var c)
Снаружи блока: `1 2 30` (глобальные a и b не изменились, а var c изменился)

**Задача 2.** Что выведет код? Объясни почему

```javascript
const user = { name: "Анна" };
user.name = "Борис";
console.log(user.name); // ?

user = { name: "Вика" };
console.log(user.name); // ?
```

Разбор:
`user.name = "Борис"` - меняем свойство объекта, ошибки нет, const позволяет менять содержимое. Вывод: `"Борис"`

`user = { name: "Вика" }` - пытаемся переприсвоить саму переменную. const запрещает это. Ошибка: `TypeError: Assignment to constant variable`. Второй console.log не выполнится - код упадёт раньше

**Задача 3.** Что выведет код? Объясни почему

```javascript
let score = 100;
score = 150;
console.log(score); // ?

const maxScore = 200;
maxScore = 250;
console.log(maxScore); // ?
```

Разбор:
`let score` - можно менять. `score = 150` сработает, вывод: `150`

`const maxScore` - нельзя переприсвоить. `maxScore = 250` вызовет ошибку `TypeError: Assignment to constant variable`. Второй console.log не выполнится

**Задача 4.** Что выведет код? Объясни почему

```javascript
var x = 1;
var x = 2;
console.log(x); // ?

let y = 1;
let y = 2;
console.log(y); // ?
```

Разбор:
`var x` можно объявить дважды - вторая строка просто перезапишет значение. Вывод: `2`

`let y` нельзя объявить повторно. Вторая строка `let y = 2` вызовет ошибку `SyntaxError: Identifier 'y' has already been declared`. Код не выполнится вообще - ошибка синтаксиса

**Задача 5.** Что выведет код? Объясни почему

```javascript
const fruits = ["яблоко", "груша"];
fruits.push("банан");
console.log(fruits); // ?

fruits = ["апельсин"];
console.log(fruits); // ?
```

Разбор:
`fruits.push("банан")` - меняем содержимое массива, ошибки нет. Вывод: `["яблоко", "груша", "банан"]`

`fruits = ["апельсин"]` - пытаемся переприсвоить переменную. const запрещает. Ошибка: `TypeError: Assignment to constant variable`. Второй console.log не выполнится

**Итог:**
- `let` - если значение будет меняться
- `const` - если значение не будет меняться (используй по умолчанию)
- `var` - просто забудь

На собеседовании могут спросить про различия - теперь ты знаешь что ответить

О том, почему `var` утекает из блока, почему `let` не виден снаружи и что такое TDZ - в посте про область видимости
