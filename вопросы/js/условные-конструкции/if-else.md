## if...else

`if` проверяет условие в скобках. Если оно истинно ([truthy](../типы-данных/2026-06-19-01-truthy-false.md)) - выполняет блок кода. Если ложно (falsy) - пропускает

**`if` (простое условие)**

```javascript
let age = 20;

if (age >= 18) {
    console.log("Можно входить");
}
// "Можно входить" - условие истинно, блок выполняется
```

**`else` (иначе)**

```javascript
let age = 15;

if (age >= 18) {
    console.log("Можно входить");
} else {
    console.log("Нельзя, рано ещё");
}
// "Нельзя, рано ещё" - условие ложно, выполняется else
```

**`if...else if...else` (несколько условий)**

`if` - «**если** условие истинно, выполняю этот блок»

`else if` - «**иначе** если предыдущее было ложно, проверяю новое условие»

`else` - «**иначе** (всё предыдущее ложно), выполняю этот блок»

```javascript
let age = 12;

if (age >= 18) {
    console.log("Взрослый");
} else if (age >= 13) {
    console.log("Подросток");
} else {
    console.log("Ребёнок");
}
// "Ребёнок" - первые два условия ложны, сработал else
```

Важно: как только одно условие сработало, остальные не проверяются. Порядок условий имеет значение

---

`if` можно писать и без фигурных скобок, если внутри только одна строка:

```javascript
if (age >= 18) console.log("Можно");
else console.log("Нельзя");
```

Но со скобками читаемее и безопаснее - проще добавить ещё строку и не сломать логику

Ещё `if` часто используют в функциях с `return`:

```javascript
function checkAccess(age) {
    if (age >= 18) return "Можно";
    return "Нельзя";
}
```

Если условие истинно - функция сразу возвращает результат и выходит. `else` не обязателен, потому что `return` уже прерывает выполнение

---

**Простые задачи**

```javascript
// 1. Что выведет?
let x = 5;
if (x > 3) {
    console.log("Больше 3");
}
```

<details>
<summary>Ответ</summary>

`"Больше 3"` - 5 > 3, условие истинно

</details>

```javascript
// 2. Что выведет?
let y = 0;
if (y) {
    console.log("Истина");
} else {
    console.log("Ложь");
}
```

<details>
<summary>Ответ</summary>

`"Ложь"` - 0 это falsy, условие ложно, срабатывает else

</details>

```javascript
// 3. Что выведет?
let z = 7;
if (z > 10) {
    console.log("Больше 10");
} else if (z > 5) {
    console.log("Больше 5");
} else {
    console.log("5 или меньше");
}
```

<details>
<summary>Ответ</summary>

`"Больше 5"` - первое условие ложно (7 не больше 10), второе истинно

</details>

---

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let a = 10;
if (a > 5)
    if (a > 8)
        console.log("A");
    else
        console.log("B");
else
    console.log("C");
```

<details>
<summary>Ответ</summary>

`"A"` - оба условия истинны (10 > 5 и 10 > 8). `else` относится к ближайшему `if` (второму). Без скобок код запутан, но логика такая

</details>

```javascript
// 5. ⭐ Что выведет?
let b = 3;
if (b > 5) {
    console.log("Больше 5");
} else if (b > 8) {
    console.log("Больше 8");
} else if (b > 1) {
    console.log("Больше 1");
} else {
    console.log("1 или меньше");
}
```

<details>
<summary>Ответ</summary>

`"Больше 1"` - первые два условия ложны, третье истинно. Но заметь: `b > 8` никогда не сработает, если `b > 5` ложно - потому что число не может быть одновременно меньше 5 и больше 8. Порядок условий важен

</details>
