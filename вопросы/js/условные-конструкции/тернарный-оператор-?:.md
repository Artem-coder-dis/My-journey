## Тернарный оператор `?:`

Тернарный оператор - это короткая запись `if...else`. Состоит из трёх частей:

```javascript
условие ? выражениеЕслиИстина : выражениеЕслиЛожь
```

**Пример 1:**

```javascript
let age = 20;
let access = age >= 18 ? "Можно" : "Нельзя";
console.log(access); // "Можно"
```

То же самое через `if...else`:

```javascript
let access;
if (age >= 18) {
    access = "Можно";
} else {
    access = "Нельзя";
}
```

Тернарник короче, но читается тяжелее. Для простых условий ещё нормально, для сложных - лучше `if`

---

**Необычный порядок во вложенных тернарниках**

Когда тернарники вкладывают друг в друга, они читаются справа налево. Это непривычно, но так работает JS:

```javascript
let score = 85; // ↓ условие
let grade = score >= 90 ? "A" :
                     // ↑ "если"
            score >= 80 ? "B" :           // : ← "иначе/иначе если"
            score >= 70 ? "C" : "D";
console.log(grade); // "B"
```

JS сначала проверяет `score >= 90` - нет. Идёт к правой части после `:`, а там снова тернарник. Проверяет `score >= 80` - да, возвращает `"B"` и дальше не идёт

Такую цепочку форматируют с отступами, чтобы было понятно. Читается: «если... иначе если... иначе», как цепочка `if`...`else if`...`else`

Первое условие - если истинно, возвращает левую часть, если ложно - идёт к правой части, где может быть следующее условие. И так до конца

---

**Простые задачи**

```javascript
// 1. Что выведет?
let x = 10;
let result = x > 5 ? "Больше" : "Меньше";
console.log(result);
```

<details>
<summary>Ответ</summary>

`"Больше"` - 10 > 5 истинно, берётся левое выражение

</details>

```javascript
// 2. Что выведет?
let loggedIn = false;
let message = loggedIn ? "Добро пожаловать" : "Войдите";
console.log(message);
```

<details>
<summary>Ответ</summary>

`"Войдите"` - `loggedIn` равен false, берётся правое выражение

</details>

**Пример 2**

```javascript
// 3. Что выведет?
let name = "";
let display = name ? name : "Аноним";
console.log(display);
```

<details>
<summary>Ответ</summary>

`"Аноним"` - пустая строка это falsy, берётся правое выражение

</details>

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let a = 0;
let b = a ? (a > 0 ? "положительное" : "отрицательное") : "ноль";
console.log(b);
```

<details>
<summary>Ответ</summary>

`"ноль"` - `a` равен 0 (falsy), поэтому сразу берётся правое выражение после `:`. До вложенного тернарника `(a > 0 ? ...)` дело не доходит. JS не вычисляет то, что не нужно - это называется «короткое замыкание»

если `a` truthy, идём к выражению сразу после ? (в скобках). Если `falsy` - идём к выражению после `:` (это "ноль")

Если бы `a` был, например, `5`:

`5 ?` - truthy, идём в скобки.

`5 > 0 ?` - истинно → "положительное".

`b` = "положительное"

</details>

```javascript
// 5. ⭐ Что выведет?
let n = 15;
let type = n > 100 ? "огромное" :
           n > 50 ? "большое" :
           n > 10 ? "среднее" :
           n > 5 ? "маленькое" : "крошечное";
console.log(type);
```

<details>
<summary>Ответ</summary>

`"среднее"` - `n > 100` нет, `n > 50` нет, `n > 10` да. Дальше проверки не идут

Важно: если бы сначала проверялось `n > 5`, оно бы сработало первым и вернуло `"маленькое"`. Порядок условий имеет значение

</details>
