## switch...case

`switch` - это ещё один способ написать условие с несколькими вариантами. Работает как цепочка `if...else if...else`, но выглядит иначе

**Пример 1**

```javascript
let fruit = "яблоко";

switch (fruit) {
    case "банан":
        console.log("Жёлтый");
        break;
    case "яблоко":
        console.log("Красное или зелёное");
        break;
    case "груша":
        console.log("Зелёная");
        break;
    default:
        console.log("Неизвестный фрукт");
}
// "Красное или зелёное"
```

**Как это работает:**

1. `switch(fruit)` - берёт значение `fruit` и ищет совпадение
2. `case "банан"` - fruit равен `"банан"`? Нет, идём дальше
3. `case "яблоко"` - fruit равен `"яблоко"`? Да, выполняем этот блок
4. `break` - выходим из `switch`, дальше не идём
5. Если ни один `case` не совпал - выполняется `default`

---

**Особенность: проваливание без `break`**

Если забыть `break`, выполнение «провалится» в следующий `case`. Это не ошибка, а особенность, если ты не хотел проваливания

**Пример 2**

```javascript
let fruit = "яблоко";

switch (fruit) {
    case "банан":
        console.log("Жёлтый");
        break;
    case "яблоко":
        console.log("Красное или зелёное");
        // нет break - проваливаемся дальше!
    case "груша":
        console.log("Фрукт");
        break;
    default:
        console.log("Неизвестно");
}
// "Красное или зелёное"
// "Фрукт"
```

Сработал `case "яблоко"`, но `break` нет, поэтому выполнился и следующий `case "груша"`. Иногда это используют специально, чтобы сгруппировать несколько вариантов:

**Пример 3**

```javascript
let color = "синий";

switch (color) {
    case "красный":
    case "синий":
    case "зелёный":
        console.log("Основной цвет");
        break;
    case "оранжевый":
    case "фиолетовый":
        console.log("Дополнительный цвет");
        break;
    default:
        console.log("Неизвестный цвет");
}
// "Основной цвет"
```

`"красный"`, `"синий"` и `"зелёный"` ведут к одному блоку. `break` стоит только после общего блока, а не после каждого `case`. Это удобно для группировки

В if это выглядело бы так:

```javascript
if (color === "красный" || color === "синий" || color === "зелёный") {
    console.log("Основной цвет");
}
```
---

При написании этого поста задался таким вопросом: можно ли писать в строку? И, на моё удивление, оказалось, можно. `switch` можно писать и в одну строку, если код внутри `case` короткий:

**Пример 4**

```javascript
switch (fruit) {
    case "банан": console.log("Жёлтый"); break;
    case "яблоко": console.log("Красное или зелёное"); break;
    case "груша": console.log("Зелёная"); break;
    default: console.log("Неизвестный фрукт");
}
```

Но с переносами строк читается легче, особенно когда вариантов много

---

**Простые задачи**

```javascript
// 1. Что выведет?
let day = 3;

switch (day) {
    case 1:
        console.log("Пн");
        break;
    case 2:
        console.log("Вт");
        break;
    case 3:
        console.log("Ср");
        break;
    default:
        console.log("Выходной");
}
```

<details>
<summary>Ответ</summary>

`"Ср"` - `day` равен 3, сработал `case 3`, `break` остановил выполнение

</details>

```javascript
// 2. Что выведет?
let x = "A";

switch (x) {
    case "A":
        console.log("Первая");
    case "B":
        console.log("Вторая");
        break;
    default:
        console.log("Другая");
}
```

<details>
<summary>Ответ</summary>

`"Первая"` и `"Вторая"` - `case "A"` сработал, но `break` нет, поэтому выполнился и следующий `case "B"`. После него `break` остановил выполнение

</details>

```javascript
// 3. Что выведет?
let num = 5;

switch (num) {
    case 10:
        console.log("Десять");
        break;
    case 5:
        console.log("Пять");
        break;
    case 1:
        console.log("Один");
        break;
    default:
        console.log("Другое число");
}
```

<details>
<summary>Ответ</summary>

`"Пять"` - `num` равен 5, сработал `case 5`, `break` остановил выполнение

</details>

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let lang = "ru";

switch (lang) {
    case "en":
        console.log("Hello");
        break;
    case "ru":
    case "uk":
    case "by":
        console.log("Привет");
        break;
    case "de":
        console.log("Hallo");
        break;
    default:
        console.log("Неизвестный язык");
}
```

<details>
<summary>Ответ</summary>

`"Привет"` - `"ru"` входит в группу с `"uk"` и `"by"`. У `case "ru"` нет своего кода и нет `break`, поэтому выполнение переходит к `case "uk"`, потом к `case "by"`, где написан `console.log("Привет")` и стоит `break`. Это группировка вариантов

</details>

```javascript
// 5. ⭐ Что выведет?
let n = 0;

switch (n) {
    case 0:
        console.log("Ноль");
    case 1:
        console.log("Один");
    case 2:
        console.log("Два");
        break;
    default:
        console.log("Много");
}
```

<details>
<summary>Ответ</summary>

`"Ноль"`, `"Один"`, `"Два"` - `case 0` сработал, но `break` нет. Выполнение провалилось через `case 1` и `case 2`, пока не встретился `break` после `case 2`

</details>

---

`switch` удобен, когда нужно сравнить одно значение с множеством вариантов. Но если условий мало или они сложные (с `>`, `<`, `&&`), лучше использовать `if...else`

**Пример 5**

Проверка возраста с диапазонами:

```javascript
// switch не подходит - нельзя написать case age > 18
// Пришлось бы писать case для каждого возраста: 18, 19, 20...

// if...else — подходит идеально:
if (age >= 18 && hasLicense) {
    console.log("Можно водить");
} else if (age >= 18 && !hasLicense) {
    console.log("Нужны права");
} else {
    console.log("Рано ещё");
}
```
**Пример 6**

Или проверка нескольких переменных:

```javascript
// switch не подходит - проверяется только одно значение
// if...else — подходит:
if (isAdmin && isLoggedIn) {
    console.log("Админ-панель");
} else if (isLoggedIn) {
    console.log("Личный кабинет");
} else {
    console.log("Войдите");
}
```

**Пример 7**

Сравнение

```javascript
// Задача: определить тип напитка по названию

// Через switch - удобно, когда чёткие значения:
let drink = "чай";

switch (drink) {
    case "чай":
    case "кофе":
        console.log("Горячий напиток");
        break;
    case "сок":
    case "лимонад":
        console.log("Холодный напиток");
        break;
    default:
        console.log("Неизвестный напиток");
}
// "Горячий напиток"
```

```javascript
// Через if - удобно, когда условия сложнее:
let drink = "чай";
let temp = 80;

if (drink === "чай" && temp > 60) {
    console.log("Горячий чай, подождите пока остынет");
} else if (drink === "чай" && temp <= 60) {
    console.log("Чай готов к употреблению");
} else if (drink === "кофе" && temp > 70) {
    console.log("Горячий кофе, подождите");
} else if (drink === "кофе" && temp <= 70) {
    console.log("Кофе готов");
} else {
    console.log("Напиток готов");
}
// "Горячий чай, подождите пока остынет"
```

Одна и та же задача может решаться обоими способами

`switch` - когда сравниваем одно значение с несколькими вариантами

`if` - когда условий несколько и они сложные (с `>`, `<`, `&&`)
