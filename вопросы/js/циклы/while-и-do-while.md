## Цикл while

### Этап 1 - `while`

`while` - это цикл, который выполняется, **пока** условие истинно. В отличие от `for`, у него нет встроенного счётчика - только условие в скобках

```javascript
while (условие) {
    // тело цикла - выполняется, пока условие true
}
```

**Как это работает:**

```javascript
let i = 0;

while (i < 3) {
    console.log(i);
    i++;
}
// 0, 1, 2
```

По шагам:
1. Проверяется условие `i < 3`. `0 < 3` - да, выполняем тело
2. Выводим 0, увеличиваем `i` до 1
3. Снова проверка: `1 < 3` - да, выводим 1, `i = 2`
4. `2 < 3` - да, выводим 2, `i = 3`
5. `3 < 3` - нет, цикл остановился

Если забыть `i++`, условие всегда будет `true`, и цикл станет бесконечным, а страница зависнет

**Когда использовать `while` вместо `for`:**

`for` - когда знаем точное количество итераций (перебор массива, от 1 до 10)
`while` - когда количество итераций неизвестно заранее (поиск элемента, ожидание ответа, работа с вводом пользователя)

Пример с неизвестным количеством - ищем первое число, кратное 7 и 9 одновременно:

```javascript
let num = 1;

while (num % 7 !== 0 || num % 9 !== 0) {  // Пока num при делении на 7 даёт остаток не 0 ИЛИ пока num при делении на 9 даёт остаток не 0
    num++;                                // Будет выполняться тело
}


console.log(num); // 63 - первое число, которое делится и на 7, и на 9

```
Почему 63 если условие ИЛИ, а как же например 14 / 7 = 2?

Потому что 14 делится на 7, но НЕ делится на 9. Условие || требует, чтобы цикл продолжался, пока **хотя бы одно** из условий истинно

Мы не знаем, сколько шагов потребуется, поэтому `while` здесь удобнее, чем `for`

**Обратный отсчёт:**

```javascript
let i = 5;

while (i > 0) {
    console.log(i);
    i--;
}
// 5, 4, 3, 2, 1
```

**Накопление в строку:**

```javascript
let result = "";
let i = 0;

while (i < 5) {
    result += "*";
    i++;
}

console.log(result); // *****
```

**Простые задачи**

```javascript
// 1. Что выведет?
let i = 5;
while (i > 0) {
    console.log(i);
    i--;
}
```

<details>
<summary>Ответ</summary>

`5, 4, 3, 2, 1` - обратный отсчёт, 0 уже не выводится

</details>

```javascript
// 2. Что выведет?
let i = 0;
while (i < 3) {
    i++;
    console.log(i);
}
```

<details>
<summary>Ответ</summary>

`1, 2, 3` - `i++` увеличивает до вывода, поэтому первый вывод - 1. Когда `i = 3`, `3 < 3` - false, но `console.log(3)` уже сработал

</details>

```javascript
// 3. Что выведет?
let i = 0;
while (i < 3) {
    console.log(i);
}
```

<details>
<summary>Ответ</summary>

Бесконечный цикл - `i` не меняется, `0 < 3` всегда true

</details>

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let str = "";
let i = 0;
while (i < 5) {
    str += i;
    i++;
}
console.log(str);
```

<details>
<summary>Ответ</summary>

`"01234"` - числа склеиваются в строку, потому что `str` - строка

</details>

```javascript
// 5. ⭐ Что выведет?
let sum = 0;
let i = 1;
while (i <= 5) {
    sum += i;
    i++;
}
console.log(sum);
```

<details>
<summary>Ответ</summary>

`15` - сумма чисел от 1 до 5 (1+2+3+4+5=15)

</details>
