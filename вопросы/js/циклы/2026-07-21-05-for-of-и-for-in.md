## for...of и for...in

Этот пост разбит на 2 этапа. Первый - база, второй - углубление, когда дойдёшь до объектов

---

### Этап 1: for...of и знакомство с for...in

**Пример 1. `for...of`** - перебирает **значения** массива или строки

```javascript
let arr = [10, 20, 30];

for (let item of arr) {
    console.log(item);
}
// 10, 20, 30
```

`item` - это сразу элемент массива, не индекс. Не нужно писать `arr[i]`

**Пример 2. `for...in`** - перебирает **ключи** объекта

```javascript
let obj = {name: "Анна", age: 25};

for (let key in obj) {
    console.log(key, obj[key]);
}
// "name Анна", "age 25"
```

`key` - это ключ (строка), значение достаём через `obj[key]`

---

**Главное правило:**
- `for...of` - для массивов и строк (перебирает значения)
- `for...in` - для объектов (перебирает ключи)

**Типичная ошибка:** использовать `for...in` для массивов. Он перебирает индексы как строки (`"0"`, `"1"`, `"2"`), а не элементы. Для массивов всегда `for...of`

**Пример 4**

```javascript
// Неправильно для массива
for (let i in arr) {
    console.log(i); // "0", "1", "2" - строки, не числа
}

// Правильно для массива
for (let item of arr) {
    console.log(item); // 10, 20, 30
}
```

---

```javascript
for (let item of arr) {
    console.log(item);
}
```

`true, 46, -6` - `for...of` перебирает значения

<summary>Ответ</summary>

</details>

### Этап 2: for...in подробнее (после изучения объектов)

Когда дойдёшь до объектов, возвращайся к этому этапу. Здесь разбираются ошибки, которые я совершал, когда только начинал использовать `for...in`

Ещё совсем недавно я путался с `for...of`, `for...in` и `Object.values`, `Object.keys`. Когда решил простые задачи, думал, что легко. Но когда сложность повысилась совсем ненамного, я наделал много ошибок

**Задача 1:** Возвращает первый ключ, значение которого равно value. Если нет - null.

Я написал:

```javascript
function findKeyByValue(obj, value) {
    for (let item of Object.values(obj)) {
        if (item === value) return obj.item;
        return null;
    }
}

console.log(findKeyByValue({a: 1, b: 2, c: 1}, 1)); // undefined 
console.log(findKeyByValue({a: 1, b: 2}, 5)); // null
```

**В чём ошибки:**

1. `for...of Object.values(obj)` - `item` здесь принимает **значение**, а не ключ. То есть `item` будет равен `1`, потом `2`, потом `1`. Это значение, а не имя свойства. Поэтому `obj.item` ищет свойство с буквальным именем `"item"`, а не `"a"`

2. `return null` внутри цикла - сработает на первой же итерации, если `item !== value`. Функция проверит первое значение и сразу выйдет с `null`, не дойдя до остальных. `return null` должен быть **после** цикла, когда все значения проверены и ничего не найдено

3. Доступ к ключу - я перебирал значения (`Object.values`), но мне нужно было вернуть **ключ**. Значение у меня было - это `item`. Но как по значению получить ключ? Либо перебирать не значения, а ключи, либо перебирать и ключи и значения сразу (`for...in` или `Object.entries`)

Потом исправил на:

```javascript
for (let item in Object.keys(obj)) {
    if (item === value) return obj[item];
}
return null;
```

Но всё ещё не то. `Object.keys(obj)` возвращает **массив** ключей: `["a", "b", "c"]`. А `for...in` по массиву перебирает **индексы** массива: `"0"`, `"1"`, `"2"`. То есть `item` будет строкой `"0"`, потом `"1"`, потом `"2"`. Это индексы, не ключи объекта. `obj[item]` ищет свойство с именем `"0"` - таких нет, вернёт `undefined`

**Правильное решение:**

```javascript
function findKeyByValue(obj, value) {
    for (let key in obj) {
        if (obj[key] === value) return key;
    }
    return null;
}

console.log(findKeyByValue({a: 1, b: 2, c: 1}, 1));   // "a"
console.log(findKeyByValue({a: 1, b: 2}, 5));        // null
```

Теперь `key` на каждой итерации становится ключом объекта (строкой `"a"`, `"b"`, `"c"`). `obj[key]` - это значение по этому ключу. Сравниваем с `value`, если совпало - возвращаем ключ

**Как будет выглядеть задача, если подставить значения:**

```javascript
for (let key in obj) {                    // key = "a", потом "b", потом "c"
    if (obj[key] === value) return key;   // obj["a"] === 1? да → возвращаем "a"
}
```

**Ещё один пример с моими ошибками:**

**Задача 2:** Суммировать все положительные числовые значения объекта. Отрицательные и нечисловые пропустить

Я написал:

```javascript
function sumPositive(obj) {
    let result = 0;

    for (let key in obj) {
        if (key > 0) result += key;
    }

    return result;
}

console.log(sumPositive({a: 3, b: -1, c: 7, d: "hi"})); // 0
```

**Три ошибки:**

1. `key > 0` - `key` это ключ (строка `"a"`, `"b"`...). Сравнивать с нулём нужно **значение**: `obj[key] > 0`

2. `result += key` - прибавлял ключ (строку). Нужно прибавлять значение: `result += obj[key]`

3. Нет проверки `typeof` - даже после исправления `obj[key] > 0` сломается на строке `"hi" > 0` - даст `false`, что в данном случае безопасно, но на других операциях могло бы вызвать ошибку. Лучше всегда писать: `typeof obj[key] === "number" && obj[key] > 0`

**Правильное решение:**

```javascript
function sumPositive(obj) {
    let result = 0;

    for (let key in obj) {
        if (typeof obj[key] === "number" && obj[key] > 0) {
            result += obj[key];
        }
    }

    return result;
}

console.log(sumPositive({a: 3, b: -1, c: 7, d: "hi"})); // 10
```

---

**Итог:**

- `for...of` - для массивов и строк (значения)
- `for...in` - для объектов (ключи)
