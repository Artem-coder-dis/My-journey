## Цикл for

### Этап 1: for

`for` - это цикл, который повторяет код заданное количество раз. Состоит из трёх частей в скобках:

```javascript
for (начало; условие; шаг) {
    // тело цикла - выполняется на каждой итерации
}
```

**Как это работает:**

```javascript
for (let i = 0; i < 3; i++) {
    console.log(i);
}
// 0, 1, 2
```

`i++` увеливает счётчик на `1`, точно также как `i + 1` или `i += 1`

По шагам:
1. `let i = 0` - создали счётчик (выполняется один раз перед циклом)
2. `i < 3` - 0 < 3, да → выполняем тело, выводим 0
3. `i++` - i становится 1
4. `i < 3` - 1 < 3, да → выводим 1
5. `i++` - i становится 2
6. `i < 3` - 2 < 3, да → выводим 2
7. `i++` - i становится 3
8. `i < 3` - 3 < 3, нет → цикл остановился

Тело выполнилось 3 раза (для i = 0, 1, 2). Итерация - это один проход цикла

---

**Разные способы использовать for**

Обратный отсчёт:

```javascript
for (let i = 5; i > 0; i--) {
    console.log(i);
}
// 5, 4, 3, 2, 1
```

Шаг +2 (только чётные):

```javascript
for (let i = 0; i <= 10; i += 2) {
    console.log(i);
}
// 0, 2, 4, 6, 8, 10
```

Не с нуля:

```javascript
for (let i = 3; i <= 7; i++) {
    console.log(i);
}
// 3, 4, 5, 6, 7
```

С использованием счётчика внутри тела:

```javascript
for (let i = 1; i <= 3; i++) {
    console.log("Итерация " + i);
}
// "Итерация 1", "Итерация 2", "Итерация 3"
```

---

**for в функции с return**

Когда условие срабатывает, `return` сразу выходит из функции и цикла:

```javascript
function findFirstEven(arr) {
    for (let i = 0; i < arr.length; i++) {
        if (arr[i] % 2 === 0) return arr[i];  // условие если (число при делении на 2 даёт остаток 0 - то это чётное)
    }                                         // i - это индекс числа, подробнее в массивах
    return null;
}

console.log(findFirstEven([1, 3, 4, 7])); // 4 - первое чётное
```

Цикл остановился на 4, дальше не пошёл. `return` прерывает и цикл, и функцию

---

**Накопление в переменную**

Цикл может не просто выводить, а собирать результат:

```javascript
let result = "";

for (let i = 0; i < 5; i++) {
    result += "*";
}

console.log(result); // *****
```

На каждой итерации к строке добавляется одна звёздочка. После цикла - вывод всей строки

---

**Особенность шага: `i++` и `++i`**

Шаг выполняется **после** тела цикла, поэтому первый вывод всегда с начальным значением:

```javascript
for (let i = 0; i < 3; i++) {
    console.log(i);
}
// 0, 1, 2 - первый вывод 0, потому что i++ ещё не сработал
```

Порядок на первой итерации:
1. `let i = 0` - создали счётчик
2. `i < 3` - проверили условие
3. Выполнили тело - вывели 0
4. `i++` - увеличили счётчик (после тела)

Разница между `i++` и `++i` в цикле не имеет значения - оба увеличивают счётчик на 1. Результат будет одинаковым. Но технически:

- `i++` — сначала возвращает старое значение, потом увеличивает
- `++i` — сначала увеличивает, потом возвращает новое

В цикле это неважно, потому что возвращаемое значение шага не используется. Но в других местах (присваивание, условие) разница есть


---

**Простые задачи**

```javascript
// 1. Что выведет?
for (let i = 0; i < 3; i++) {
    console.log(i);
}
```

<details>
<summary>Ответ</summary>

`0, 1, 2` - три итерации, i от 0 до 2

</details>

```javascript
// 2. Что выведет?
for (let i = 1; i <= 3; i++) {
    console.log(i);
}
```

<details>
<summary>Ответ</summary>

`1, 2, 3` - старт с 1, `<=` включает 3 (меньше или равно)

</details>

```javascript
// 3. Что выведет?
for (let i = 5; i > 0; i--) {
    console.log(i);
}
```

<details>
<summary>Ответ</summary>

`5, 4, 3, 2, 1` - обратный отсчёт, 0 уже не выводится

</details>

---

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let result = "";

for (let i = 0; i < 5; i++) {
    result += i;
}

console.log(result);
```

<details>
<summary>Ответ</summary>

`"01234"` - числа склеиваются в строку, потому что `result` - строка

</details>

```javascript
// 5. ⭐ Что выведет?
function countTo(n) {
    for (let i = 1; i <= n; i++) {
        if (i === 3) return i;
        console.log(i);
    }
}

countTo(5);
```

<details>
<summary>Ответ</summary>

`1, 2` - на i = 3 срабатывает `return`, функция выходит, `console.log(3)` не выполняется

</details>

### Этап 2: вложенный цикл for

Вложенный цикл - это цикл внутри другого цикла. Тема <s>сложная</s> непростая, но если разобраться сейчас, дальше будет легче. На собеседованиях задачи с вложенными циклами встречаются часто, поэтому стоит уделить им внимание и хорошо отработать
