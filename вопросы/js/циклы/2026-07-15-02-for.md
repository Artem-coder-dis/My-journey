## Цикл for

### Этап 1: for

`for` - это цикл, который повторяет код заданное количество раз. Состоит из трёх частей в скобках:

```javascript
for (начало; условие; шаг) {
    // тело цикла - выполняется на каждой итерации
}
```

**Как это работает:**

**Пример 1**

```javascript
for (let i = 0; i < 3; i++) {
    console.log(i);
}
// 0, 1, 2
```

`i++` увеливает счётчик на `1`, точно также как `i + 1` или `i += 1`

По шагам:
1. `let i = 0` - создали счётчик (выполняется один раз перед циклом)
2. `i < 3` – `0 < 3`, да → выполняем тело, выводим `0`
3. `i++` – `i` становится `1`
4. `i < 3` – `1 < 3`, да → выводим `1`
5. `i++` – `i` становится `2`
6. `i < 3` – `2 < 3`, да → выводим `2`
7. `i++` – `i` становится `3`
8. `i < 3` – `3 < 3`, нет → цикл остановился

Тело выполнилось `3` раза (для `i = 0, 1, 2`). Итерация – это один проход цикла

Я сначала путался как правильно условие ставить, но всё довольно просто, условие выполняется **пока**  `i < 3`, то есть цикл выполняет условие **до тех пор**, пока `i` меньше `7`, как только `i` станет больше или равно 7, цкил сразу прекратится

---

**Разные способы использовать for**

**Пример 2.** Обратный отсчёт:

```javascript
for (let i = 5; i > 0; i--) {
    console.log(i);
}
// 5, 4, 3, 2, 1
```

**Пример 3.** Шаг +2 (только чётные):

```javascript
for (let i = 0; i <= 10; i += 2) {
    console.log(i);
}
// 0, 2, 4, 6, 8, 10
```

**Пример 4.** Не с нуля:

```javascript
for (let i = 3; i <= 7; i++) {
    console.log(i);
}
// 3, 4, 5, 6, 7
```

**Пример 5.** С использованием счётчика внутри тела:

```javascript
for (let i = 1; i <= 3; i++) {
    console.log("Итерация " + i);
}
// "Итерация 1", "Итерация 2", "Итерация 3"
```

---

**for в функции с return**

Когда условие срабатывает, `return` сразу выходит из функции и цикла:

**Пример 6.** 

```javascript
function findFirstEven(arr) {
    for (let i = 0; i < arr.length; i++) {
        if (arr[i] % 2 === 0) return arr[i];  // условие если (число при делении на 2 даёт остаток 0 - то это чётное)
    }                                         // i - это индекс числа, подробнее в массивах
    return null;
}

console.log(findFirstEven([1, 3, 4, 7])); // 4 - первое чётное
```

Цикл остановился на 4, дальше не пошёл. `return` прерывает и цикл, и функцию

---

**Накопление в переменную**

Цикл может не просто выводить, а собирать результат:

**Пример 8.** 

```javascript
let result = "";

for (let i = 0; i < 5; i++) {
    result += "*";
}

console.log(result); // *****
```

На каждой итерации к строке добавляется одна звёздочка. После цикла - вывод всей строки

---

**Особенность шага: `i++` и `++i`**

Шаг выполняется **после** тела цикла, поэтому первый вывод всегда с начальным значением:

**Пример 9.** 

```javascript
for (let i = 0; i < 3; i++) {
    console.log(i);
}
// 0, 1, 2 - первый вывод 0, потому что i++ ещё не сработал
```

Порядок на первой итерации:
1. `let i = 0` - создали счётчик
2. `i < 3` - проверили условие
3. Выполнили тело - вывели 0
4. `i++` - увеличили счётчик (после тела)

Разница между `i++` и `++i` в цикле не имеет значения - оба увеличивают счётчик на 1. Результат будет одинаковым. Но технически:

- `i++` - сначала возвращает старое значение, потом увеличивает
- `++i` - сначала увеличивает, потом возвращает новое

В цикле это неважно, потому что возвращаемое значение шага не используется. Но в других местах (присваивание, условие) разница есть

### Этап 2: вложенный цикл for

Вложенный цикл - это цикл внутри другого цикла. Тема <s>сложная</s> непростая, но если разобраться сейчас, дальше будет легче. На собеседованиях задачи с вложенными циклами встречаются часто, поэтому стоит уделить им внимание и хорошо отработать


**Пример 1**
```javascript
for (let str = 0; str < 4; str++) {
    let result = "";

    for (let col = 0; col < 4; col++) {
        result += "*"
    }
    console.log(result);
}

```

<details>
<summary>Вывод</summary>
    
```
****
****
****
****  
```

</details>

**Что здесь происходит:**

- первым шагом мы создаём внешний цикл который проходится по строкам
- создаём переменную в которую будет складываться наш результат
- далее создаём внешний цикл который будет идти по столбцам и внутри к результату мы прибавляем `*`

**Важный нюанс - порядок работы вложенных циклов:**

Внутренний цикл проходится полностью после каждой итерации внешнего. Внешний сработал 1 раз - внутренний срабатывает 4 раза. Внешний увеличил `str` - внутренний снова проходит 4 раза, начиная с `col = 0`

- внешний цикл: `str` = 0 → внутренний отработал 4 раза → вывод строки `console.log(result);`
- внешний цикл: `str` = 1 → внутренний снова с `col = 0`, отработал 4 раза → вывод строки
- и так до тех пор, пока внешний цикл не завершится (`str < 4`)

Внутренний цикл **всегда** начинается заново с `col = 0`, потому что `let col = 0` выполняется при каждом входе во внутренний цикл. Именно поэтому он «сбрасывается» на каждой новой строке

Внешний цикл накапливает `str`: 0 → 1 → 2 → 3 → завершился (условие `str < 4`). Внутренний на каждой итерации внешнего проходит `col`: 0 → 1 → 2 → 3 → завершился, и так 4 раза

---

Рассмотрим задачу посложнее:

**Задача 1** Выведи строки с количеством звёздочек, равным номеру строки от 1 до 4:
```
*
**
***
****
```

Решение:

```javascript
for (let str = 1; str <= 4; str++) {
    let result = "";

    for (let col = 1; col <= str; col++) {
        result += "*"
    }

    console.log(result)
}
```

<details>
<summary>Вывод</summary>

```
*
**
***
****
```

</details>

**Что здесь происходит:**

Внешний цикл идёт по строкам от 1 до 4

Внутренний цикл идёт по столбцам, но не до 4, как в прошлом примере, а до `str` - номера текущей строки. Поэтому на каждой строке количество звёздочек разное:

- `str = 1`: внутренний цикл `col <= 1` - 1 звёздочка → `*`
- `str = 2`: внутренний цикл `col <= 2` - 2 звёздочки → `**`
- `str = 3`: внутренний цикл `col <= 3` - 3 звёздочки → `***`
- `str = 4`: внутренний цикл `col <= 4` - 4 звёздочки → `****`

Внутренний цикл **зависит** от внешнего - его условие использует переменную `str`. Это ключевое отличие от квадрата (хоть он и выглядит как прямоугольник, но символов в нём 4х4), где внутренний цикл всегда был одинаковым. Здесь количество итераций внутреннего цикла растёт вместе с номером строки, поэтому получается треугольник

Во втором варианте (внешний по строкам 1-9, внутренний по числам 2-4) таблица выводится построчно: первая строка - умножение 2, 3, 4 на 1, вторая строка - на 2, и так далее. Это выглядит как обычная таблица, где строки - это множители, а столбцы - числа

Поэтому и поменяли - для красивого вывода

**Задача 3.** Нужно вывести квадрат 4x4, где на главной диагонали стоит X, а в остальных местах O:
```
X O O O
O X O O
O O X O
O O O X
```

Решение:

```javascript
for (let row = 1; row <= 4; row++) {
    let result = "";

    for (let col = 1; col <= 4; col++) {
        if (row === col) {
            result += "X ";
        } else {
            result += "O ";
        }
    }

    console.log(result);
}
```

<details>
<summary>Вывод</summary>

```
X O O O 
O X O O 
O O X O 
O O O X 
```

</details>

**Что здесь происходит:**

Внешний цикл идёт по строкам, внутренний - по столбцам. На каждой клетке проверяется условие `row === col` - это главная диагональ (из левого верхнего угла в правый нижний), то есть если индексы равны - ставим `X`, если нет - `O`. Так получается квадрат 4x4, где на главной диагонали стоят `X`, а в остальных местах - `O`

Это классическая задача на вложенные циклы с условием. Показывает, как можно «рисовать» фигуры, проверяя соотношение между индексами строк и столбцов

**Задача 4.** Нужно вывести квадрат 5x5, где на побочной диагонали X, остальное O:

```
O O O O X
O O O X O
O O X O O
O X O O O
X O O O O
```

Решение:

```javascript
for (let row = 1; row <= 5; row++) {
    let result = "";

    for (let col = 1; col <= 5; col++) {
        if (row + col === 6) {
            result += "X ";
        } else {
            result += "O ";
        }
    }

    console.log(result);
}
```

<details>
<summary>Вывод</summary>

```
O O O O X 
O O O X O 
O O X O O 
O X O O O 
X O O O O 
```

</details>

**Что здесь происходит:**

Внешний цикл идёт по строкам, внутренний - по столбцам. На каждой клетке проверяется условие `row + col === 6` - это побочная диагональ (из левого нижнего угла в правый верхний)

Для доски 5x5 побочная диагональ - это клетки, где сумма номера строки и номера столбца равна 6 (так как `5 + 1 = 6`). Например: `(1,5) → 1+5=6`, `(2,4) → 2+4=6`, `(3,3) → 3+3=6` и так далее

Если сумма равна 6 - ставим `X`, если нет - `O`. Так получается квадрат 5x5, где на побочной диагонали стоят `X`, а в остальных местах - `O`

Это вторая классическая задача на диагонали. В отличие от главной диагонали (`row === col`), здесь условие строится на сумме индексов

&nbsp;

Но всё-таки я так и не понял сначала, зачем мы вообще сравниваем с числом 6 и почему именно 6. Так вот: мы могли бы написать цикл с индексами от 0 и сравнивать с 4:

```javascript
// изменения
      // здесь ↓      ↓ здесь (знак)
for (let row = 0; row < 5; row++) {
    let result = "";

          // здесь ↓      ↓ и здесь
    for (let col = 0; col < 5; col++) {
        if (row + col === 4) {  // и тут, 6 заменили на 4
            result += "X ";
        } else {
            result += "O ";
        }
    }

    console.log(result);
}
```

И это работает. Вот схема диагонали по индексам (с 0):

```
(0,0) (0,1) (0,2) (0,3) (0,4)   ← X на (0,4): 0+4=4
(1,0) (1,1) (1,2) (1,3) (1,4)   ← X на (1,3): 1+3=4
(2,0) (2,1) (2,2) (2,3) (2,4)   ← X на (2,2): 2+2=4
(3,0) (3,1) (3,2) (3,3) (3,4)   ← X на (3,1): 3+1=4
(4,0) (4,1) (4,2) (4,3) (4,4)   ← X на (4,0): 4+0=4
```

В первом же случае мы сравнивали с 6, потому что начинали индексы не с 0, а с 1. Разница между 4 и 6 - это 2, и она возникает из-за того, что оба индекса сдвинуты на 1 (вместо `0+4=4` получается `1+5=6`). Оба варианта правильные, просто зависят от начального значения счётчика
