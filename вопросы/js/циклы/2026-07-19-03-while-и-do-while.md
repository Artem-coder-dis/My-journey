## Цикл while

### Этап 1: `while`

`while` - это цикл, который выполняется, **пока** условие истинно. В отличие от `for`, у него нет встроенного счётчика - только условие в скобках

```javascript
while (условие) {
    // тело цикла - выполняется, пока условие true
}
```

**Пример 1. Как это работает:**

```javascript
let i = 0;

while (i < 3) {
    console.log(i);
    i++;
}
// 0, 1, 2
```

По шагам:
1. Проверяется условие `i < 3`. `0 < 3` - да, выполняем тело
2. Выводим 0, увеличиваем `i` до 1
3. Снова проверка: `1 < 3` - да, выводим 1, `i = 2`
4. `2 < 3` - да, выводим 2, `i = 3`
5. `3 < 3` - нет, цикл остановился

Если забыть `i++`, условие всегда будет `true`, и цикл станет бесконечным, а страница зависнет

**Когда использовать `while` вместо `for`:**

`for` - когда знаем точное количество итераций (перебор массива, от 1 до 10)
`while` - когда количество итераций неизвестно заранее (поиск элемента, ожидание ответа, работа с вводом пользователя)

**Пример 2.** С неизвестным количеством - ищем первое число, кратное 7 и 9 одновременно:

```javascript
let num = 1;

while (num % 7 !== 0 || num % 9 !== 0) {  // Пока num при делении на 7 даёт остаток не 0 ИЛИ пока num при делении на 9 даёт остаток не 0
    num++;                                // Будет выполняться тело
}


console.log(num); // 63 - первое число, которое делится и на 7, и на 9

```
Почему 63 если условие ИЛИ, а как же например 14 / 7 = 2?

Потому что 14 делится на 7, но НЕ делится на 9. Условие || требует, чтобы цикл продолжался, пока **хотя бы одно** из условий истинно

Мы не знаем, сколько шагов потребуется, поэтому `while` здесь удобнее, чем `for`

**Пример 3. Обратный отсчёт:**

```javascript
let i = 5;

while (i > 0) {
    console.log(i);
    i--;
}
// 5, 4, 3, 2, 1
```

**Пример 4. Накопление в строку:**

```javascript
let result = "";
let i = 0;

while (i < 5) {
    result += "*";
    i++;
}

console.log(result); // *****
```

<details>

Бесконечный цикл - `i` не меняется, `0 < 3` всегда true

</details>

### Этап 2: do...while

`do...while` - это цикл, который сначала выполняет тело, а потом проверяет условие. Гарантирует, что тело выполнится хотя бы один раз, даже если условие ложно

```javascript
do {
    // тело цикла - выполняется хотя бы один раз
} while (условие);
```

**Как это работает:**

```javascript
let i = 0;

do {
    console.log(i);
    i++;
} while (i < 3);
// 0, 1, 2
```

По шагам:
1. Выполняется тело - выводим 0, увеличиваем `i` до 1
2. Проверяется условие `i < 3`. `1 < 3` - да, возвращаемся к телу
3. Выводим 1, `i = 2`, проверка `2 < 3` - да
4. Выводим 2, `i = 3`, проверка `3 < 3` - нет, выходим

**Главное отличие от `while`:**

```javascript
// while - условие ложно сразу, тело не выполнится ни разу
let i = 10;
while (i < 3) {
    console.log(i); // не сработает
}

// do...while - тело выполнится один раз, даже если условие ложно
let j = 10;
do {
    console.log(j); // 10 - вывел, потом проверил условие
} while (j < 3);
```

`do...while` сначала делает, потом думает. `while` - сначала думает, потом делает

**Когда использовать:**

- Когда нужно выполнить действие хотя бы один раз (запрос ввода, попытка соединения)
- Когда условие зависит от результата выполнения тела

Пример: пытаемся получить случайное число больше 0.7 - неизвестно, сколько попыток потребуется

```javascript
let num;
let attempts = 0;

do {
    num = Math.random();
    attempts++;
    console.log(`Попытка ${attempts}: ${num.toFixed(2)}`);
} while (num <= 0.7);

console.log(`Успех за ${attempts} попыток!`);
```

Мы не знаем заранее, сколько будет попыток - 1, 3 или 10. Но хотя бы одну попытку нужно сделать. Поэтому `do...while`

**Порядок важен:** `i++` до вывода или после - результат разный

```javascript
let i = 0;

do {
    i++;
    console.log(i);
} while (i < 3);
// 1, 2, 3 - i увеличивается до вывода

do {
    console.log(i);
    i++;
} while (i < 3);
// 0, 1, 2 - i увеличивается после вывода
```
