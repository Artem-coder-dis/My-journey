## Склейка строк через join

Было задание вернуть строку вида "key=value&key=value" из свойств объекта. Значения, которые не строка и не число - пропускать

Я написал:

```js
function objectToQueryString(obj) {
   let queryString = ""

   for (let key in obj) {
       if (typeof obj[key] === "string" || typeof obj[key] === "number") {
           queryString += `${key}=${obj[key]}&`
       }
   }

   return queryString
}

console.log(objectToQueryString({name: "Анна", age: 25, active: true})) // "name=Анна&age=25&"
```

Я знал, что будет ошибка из-за того что к концу строки будет клеиться `&`, но не знал как исправить, но в итоге решение получилось совсем другое

```js
function objectToQueryString(obj) {
    let parts = []

    for (let key in obj) {
        if (typeof obj[key] === "string" || typeof obj[key] === "number") {
            parts.push(`${key}=${obj[key]}`)
        }
    }

    return parts.join("&")
}

console.log(objectToQueryString({name: "Анна", age: 25, active: true})) // "name=Анна&age=25"
```

И вот почему и ответы на возможные вопросы:

**Почему массивом?**

Потому что массив удобно склеивать. У меня кусочки `"name=Анна"`, `"age=25"`. Если положить их в массив `["name=Анна", "age=25"]` и вызвать `.join("&")`, получится ровно `"name=Анна&age=25"`

`join` вставляет `&` только между элементами. В конце ничего лишнего. Без массива пришлось бы клеить вручную и потом убирать последний символ. С массивом - одна строка кода

**Что такое join и как он понимает, когда нужно вставлять "&"**

`join` - это метод массива. Склеивает все элементы массива в одну строку через разделитель, который ты указываешь в скобках

Как понимает: `join` проходит по массиву по порядку. Берёт первый элемент - `"name=Анна"`. Берёт второй элемент - перед ним ставит `&` → `"name=Анна&age=25"`. Если есть третий - перед ним тоже ставит `&`. Он знает: между элементами - разделитель, после последнего - ничего

**Чем отличаются два подхода**

В первом подходе `queryString` - это строка. Склеиваешь через `+=` и добавляешь `&` вручную. В конце остаётся лишний `&`: `"name=Анна&age=25&"`. Нужен дополнительный шаг, чтобы его убрать

Во втором подходе `parts` - это массив. Пушаешь кусочки в массив, в конце вызываешь `join("&")`. `join` ставит `&` только между элементами - лишнего нет, дополнительных шагов не нужно

Логика одинаковая, просто с массивом и `join` код чище и без костылей. Этот приём с `join` полезен для первой работы, когда нужно формировать строки с разделителями - например, параметры в URL

---

**Простое склеивание:**

```javascript
let arr = ["hello", "world", "js"];
console.log(arr.join(" ")); // "hello world js"
```

**По запятой:**

```javascript
let arr = ["apple", "banana", "grape"];
console.log(arr.join(", ")); // "apple, banana, grape"
```

**Без разделителя (по умолчанию запятая):**

```javascript
let arr = ["a", "b", "c"];
console.log(arr.join()); // "a,b,c"
```

**Пустой разделитель (склеить без пробелов):**

```javascript
let arr = ["J", "S"];
console.log(arr.join("")); // "JS"
```

**Где пригодится:**

- Собрать массив слов в предложение
- Собрать URL-параметры (`key=value&key=value`)
- Вывести массив в читаемом виде

**Пример с URL-параметрами:**

```javascript
let parts = ["name=Анна", "age=25"];
console.log(parts.join("&")); // "name=Анна&age=25"
```

**Важный нюанс:** `join` пропускает `null` и `undefined` - они превращаются в пустую строку, но не исчезают:

```javascript
let arr = ["a", null, "b", undefined, "c"];
console.log(arr.join("-")); // "a--b--c"
```

`null` и `undefined` стали пустыми местами, но разделители вокруг них остались. Разделитель вставляется строго между каждыми двумя элементами, даже если элемент пустой.

**После последнего элемента разделитель не ставится:**

```javascript
let arr = ["a", "b", "c"];
console.log(arr.join(", ")); // "a, b, c" - после "c" запятой нет
```

**Задачи**

```javascript
// 1. Что выведет?
let arr = ["x", "y", "z"];
console.log(arr.join(""));
```

<details>
<summary>Ответ</summary>

`"xyz"` - склеили без разделителя

</details>

```javascript
// 2. Что выведет?
let arr = ["hello", "world"];
console.log(arr.join(" "));
```

<details>
<summary>Ответ</summary>

`"hello world"` - склеили через пробел

</details>

```javascript
// 3. Что выведет?
let arr = [1, 2, 3];
console.log(arr.join("+"));
```

<details>
<summary>Ответ</summary>

`"1+2+3"` - числа превратились в строки и склеились через `+`

</details>

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
let arr = ["a", null, "b", undefined, "c"];
console.log(arr.join("-"));
```

<details>
<summary>Ответ</summary>

`"a--b--c"` - `null` и `undefined` превратились в пустые строки, разделители остались на своих местах. Два дефиса подряд между `a` и `b` - это `a`, пустота от `null`, дефис, `b`

</details>

```javascript
// 5. ⭐ Что выведет?
let arr = [];
console.log(arr.join(","));
```

<details>
<summary>Ответ</summary>

`""` - пустая строка. `join` для пустого массива возвращает пустую строку, разделитель не используется, потому что нечего разделять

</details>
