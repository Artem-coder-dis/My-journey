## typeof - оператор, который говорит тип

### Этап 1: typeof

`typeof` - это оператор, который возвращает строку с названием типа данных. Не сам тип, а слово в кавычках.

```js
typeof 42         // "number"
typeof "hello"    // "string"
typeof true       // "boolean"
typeof undefined  // "undefined"
```

**Задача 1: найти первое числовое значение**

```js
function findFirstNumber(obj) {
    for (let key in obj) {
        if (typeof obj[key] === "number") {
            return key
        }
    }
    return null
}

console.log(findFirstNumber({a: "hi", b: 34, c: true})) // "b"
```

`typeof obj[key] === "number"` - проверяем, что значение является числом

**Как `typeof` сравнивает число со строкой**

`typeof` всегда возвращает строку. Поэтому `typeof 34 === "number"` - это сравнение двух строк: `"number" === "number"` → `true`. Ты сравниваешь не число со строкой, а строку со строкой. Сначала `typeof` превращает значение в строку типа, потом сравниваешь

**Пример для наглядности:**

```js
let val = 34

typeof val              // "number"
typeof val === "number" // true, потому что "number" === "number"
```

**Странности typeof**

Две вещи, которые надо запомнить:

```js
typeof null        // "object" - баг, которому больше 30 лет
typeof [1, 2, 3]  // "object" - массив тоже относится к объектам
```
Почему не исправляют баг?

Потому что сломается весь интернет. Миллионы сайтов написаны с расчётом, что `typeof null === "object"`. Если исправить, старый код перестанет работать

**Как проверять правильно**

Для `null` - прямая проверка:
```js
val === null
```

Для массивов - `Array.isArray`:
```js
Array.isArray(val)
```

Для объектов (исключая null) - комбинация:
```js
typeof val === "object" && val !== null
```

**Примитив**

Примитив - это простой тип данных. Не объект, не массив, не функция. Просто значение.

Шесть примитивов в JS:
- `number` — числа (1, 42, NaN, Infinity)
- `string` — строки ("hello", 'мир')
- `boolean` — true / false
- `null` — пустота (ничего)
- `undefined` — не определено
- `symbol` — символы (редко, пока не нужно)
  
**Задача 2: отличить объект от примитива**

```js
function isObject(val) {
    return typeof val === "object" && val !== null
}

console.log(isObject({a: 1}))  // true
console.log(isObject([1, 2]))  // true
console.log(isObject(null))    // false
console.log(isObject(42))      // false
```

`typeof val === "object"` - срабатывает на объекты, массивы и `null`

`val !== null` - убирает `null`, оставляя только настоящие объекты и массивы

Если условие истинно - перед нами объект или массив. Если ложно - примитив (или `null`)

**Итог**

`typeof` - быстрый способ узнать тип. Хорош для строк, чисел, булевых. Для массивов - `Array.isArray`, для `null` - прямая проверка

### Этап 2: Тонкости typeof

Этот этап для большего углубления в тему, его не обязательно изучать сразу после 1 этапа. Знаний с 1 этапа мне хватило надолго, пока я не перешёл к повторению и не начал разбираться чуть глубже



**typeof NaN**

```javascript
console.log(typeof NaN); // "number"
```

`NaN` - это «не число», но технически оно принадлежит типу `number`

**typeof Infinity**

```javascript
console.log(typeof Infinity); // "number"
```

`Infinity` или `-Infinity` - это бесконечность, но всё равно принадлежит к типу `number`

**typeof function(){}**

```javascript
console.log(typeof function(){}); // "function"
```

Функции - это объекты, но `typeof` делает для них исключение и возвращает `"function"`

**typeof typeof 42**

```javascript
console.log(typeof typeof 42); // "string"
```

Потому что `typeof 42` возвращает строку `"number"`, а `typeof "number"` → `"string"`

**typeof undefined**

```javascript
let x;
console.log(typeof x); // "undefined"
```

`let x` объявляет переменную, но не присваивает ей значение. Когда переменная объявлена, но не инициализирована, её значение - `undefined`. `typeof undefined` возвращает `"undefined"`

**typeof []**

```javascript
console.log(typeof []); // "object"
```

Массив - это тоже объект, `typeof` не различает массив и обычный объект. Для проверки массива используют `Array.isArray()`:

```javascript
Array.isArray([]); // true
Array.isArray({}); // false
```

**Сложение и вычитание с разными типами**

```javascript
console.log(typeof (5 + "5"));   // "string"
console.log(typeof ("5" + 5));   // "string"
console.log(typeof ("5" - 5));   // "number"
```

Когда один из операндов строка, `+` всегда делает конкатенацию, независимо от порядка. Число превращается в строку и приклеивается

Конкатенация — это склеивание строк: `"Hello" + " " + "World"` → `"Hello World"`

А `-`, `*`, `/` работают только с числами, поэтому `"5" - 5` → `0` (строка превращается в число, потом вычитание). Порядок тут тоже не важен: `5 - "5"` → `0`

**typeof необъявленной переменной**

```javascript
console.log(typeof необъявленнаяПеременная); // "undefined" - без ошибки
```

`typeof` — единственный оператор, который не вызывает ошибку при обращении к необъявленной переменной. Если переменная вообще не объявлена, `typeof` всё равно вернёт `"undefined"`. Это полезно для проверки существования глобальных переменных
