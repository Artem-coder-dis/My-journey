## Типы данных в JS

Всего в JS 8 типов данных. На практике чаще всего встречаются 5 основных

### Основные типы (5)

**number** - числа: целые, дробные, специальные значения `Infinity` и `NaN`. `NaN` означает «не число», но технически принадлежит типу `number`

```javascript
let age = 25
let price = 99.9
let inf = Infinity
let notANumber = NaN
```

**string** - строки, текст в кавычках (одинарных, двойных или обратных)

```javascript
let name = "Анна"
let city = 'Москва'
let greeting = `Привет, ${name}`
```

**boolean** - логическое значение: `true` или `false`. Используется в условиях и проверках

```javascript
let isAdult = true
let hasError = false
```

**undefined** - значение не присвоено. Переменная объявлена, но пустая

```javascript
let x
console.log(x) // undefined
```

**object** - составной тип: объекты, массивы, функции, `null` (баг). Хранит набор свойств

```javascript
let user = { name: "Анна", age: 25 }
let arr = [1, 2, 3]
```

---

### Редкие типы (3)

**null** - специальное значение, означающее «ничего», «пусто». Формально `typeof null` → `"object"` (баг)

**symbol** - уникальные идентификаторы, используются редко, в продвинутых темах

**bigint** - очень большие числа, с суффиксом `n`. Нужны для работы с числами больше `2^53`

```javascript
let big = 9007199254740991n
```

---

На практике ты будешь использовать 5 основных типов: `number`, `string`, `boolean`, `undefined`, `object`. Остальные - по необходимости. `typeof` помогает определить тип значения, но помни про баг с `null` и то, что массивы - тоже `"object"`
