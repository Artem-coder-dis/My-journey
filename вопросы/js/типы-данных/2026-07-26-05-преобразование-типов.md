## Преобразование типов (coercion)

В JS значения одного типа могут превращаться в другой. Это происходит явно (ты сам вызываешь функцию) или неявно (JS делает это автоматически)

---

### Явное преобразование

Ты сам превращаешь значение в нужный тип с помощью функций  

**В строку - `String()`**

```javascript
console.log(String(42));      // "42"
console.log(String(true));    // "true"
console.log(String(null));    // "null"
console.log(String(undefined)); // "undefined"
```

**В число - `Number()`**

```javascript
console.log(Number("42"));     // 42
console.log(Number(""));       // 0 - пустая строка → 0
console.log(Number("hello"));  // NaN - не число
console.log(Number(true));     // 1
console.log(Number(false));    // 0
console.log(Number(null));     // 0
console.log(Number(undefined)); // NaN
```

**В булево - `Boolean()`**

```javascript
console.log(Boolean(0));       // false
console.log(Boolean(""));      // false
console.log(Boolean(null));    // false
console.log(Boolean(undefined)); // false
console.log(Boolean(NaN));     // false
console.log(Boolean(1));       // true
console.log(Boolean("hello")); // true
console.log(Boolean([]));      // true - пустой массив truthy
console.log(Boolean({}));      // true - пустой объект truthy
```

## Неявное преобразование

JS сам превращает типы, когда они не подходят для операции

**Строковое преобразование (когда есть `+` со строкой)**

```javascript
console.log("5" + 3);    // "53" - число превратилось в строку
console.log("Hello" + true); // "Hellotrue"
console.log("x" + null); // "xnull"
```

**Числовое преобразование (в математических операциях, кроме `+`)**

```javascript
console.log("5" - 3);    // 2 - строка превратилась в число
console.log("10" * "2"); // 20
console.log("6" / "2");  // 3
console.log(+"5");       // 5 - унарный плюс превращает в число
console.log(+true);      // 1
console.log(+false);     // 0
console.log(+null);      // 0
console.log(+undefined); // NaN
```

**Унарный плюс `+` и унарный минус `-`**

Унарный - значит, применяется к одному значению (не к двум, как бинарный `a + b`).

- `+value` - превращает значение в число, как `Number(value)`, но короче.
- `-value` - тоже превращает в число, но меняет знак на противоположный.

<details>
<summary>примеры</summary>

```javascript
console.log(+"5");       // 5 - строка стала числом
console.log(+true);      // 1
console.log(+false);     // 0
console.log(+null);      // 0
console.log(+undefined); // NaN

console.log(-"5");       // -5
console.log(-true);      // -1
console.log(-false);     // -0 (равно 0)
console.log(-null);      // -0 (равно 0)
console.log(-undefined); // NaN
```
</details>


`+` чаще используют для быстрого приведения к числу. `-` - когда нужно инвертировать знак.

**Логическое преобразование (в условиях)**

```javascript
if ("hello") { } // "hello" → true (truthy)
if (0) { }       // 0 → false (falsy)
if ([]) { }      // [] → true (truthy)
```

**Задачи**

```javascript
// 1. Что выведет?
console.log(Number("33"));
console.log(Number("  33  "));
```

<details>
<summary>Ответ</summary>

`33` и `33` - пробелы по краям игнорируются

</details>

```javascript
// 2. Что выведет?
console.log(String(123));
console.log(typeof String(123));
```

<details>
<summary>Ответ</summary>

`"123"` и `"string"` - число стало строкой

</details>

```javascript
// 3. Что выведет?
console.log(10 + "5");
console.log(10 - "5");
```

<details>
<summary>Ответ</summary>

`"105"` - `+` со строкой = склеивание. `5` - `-` всегда число, строка превратилась в число

</details>

---

**Задачи со звёздочкой ⭐**

```javascript
// 4. ⭐ Что выведет?
console.log(+"" + +"5");
console.log("" + "5" - 2);
```

<details>
<summary>Ответ</summary>

`5` и `3`

`5` - `+""` → 0, `+"5"` → 5, 0+5=5

`3` - `"" + "5"` → `"5"`, `"5" - 2` → 3

</details>

```javascript
// 5. ⭐ Что выведет?
console.log(Boolean(" ") === Boolean(""));
console.log(Number([1]) + Number([2]));
```

<details>
<summary>Ответ</summary>

`false` и `3`

`false` - `" "` (непустая строка) → `true`, `""` (пустая) → `false`

`3` - `Number([1])` → `1`, `Number([2])` → `2`, 1+2=3

</details>
